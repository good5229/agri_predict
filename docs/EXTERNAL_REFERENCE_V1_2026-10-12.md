## 2. 기존 실험과의 차이

확인한 구현은 `market_mix.py`(시장 최신가격·중량·비중), `market_lag.py`(두 시장 7일 로그변화·시장간 차이), `market_recompose.py`(시장별 예측을 중량비중으로 재구성), `garlic_mix.py`(소분류별 7/28일 비중과 최신 상대가격), `transaction_dispersion_pilot.py`(거래 분포 요약), `chronos2_market_context.py`(대표·가락·강서 세 가격열), `preserved_feature_forecasts.py`(대표가격 기존40+66 표현)다.

따라서 세부 정보 사용 자체나 시장 두 열은 새롭지 않다. 첫 후보가 검증하는 차이는 **지원되는 품목 내부 세부 셀의 복수 시점 가격을 입력 열로 보존**하고 동일 LightGBM 대조군과 짝짓는 것이다. 세부 계열 자체를 별도 학습 정답으로 쓰는 CAND_B는 이번 후보와 분리한다. 오래된 원점 cutoff가 다른 실험의 수치를 동일 조건 성능으로 가져오지 않는다.

가설은 대표가격 집계가 숨기는 세부 가격 움직임이 남아 있다는 것이다. 기존 Ridge/SARIMA의 동방향 오차는 동기이며 원인 확정이 아니다. CAND_A−CTRL_LGB로 입력의 추가 효과를, CAND_A−E106-RHS로 강한 기준 도달 여부를 구분한다. V에서 E106-RHS 대비 40셀 동일가중 MAPE 감소·MAE 비악화·coverage 무손실 중 하나라도 실패하면 T를 실행하지 않는다. 유의성은 별도 해석이며 새 통과 문턱이 아니다.

## 3. 데이터와 정보시점

원점 o, cutoff=o−1, 목표=o+h(h1~10), cutoff~목표 간격 h+1을 유지한다. 로컬 DB가 세부 필드를 보존하는 것과 필요한 다년 이력이 검증된 것은 별개다. 실제 지원 보고서에는 선택 요청/응답 출처, 기간·고유일·부호 보존 순중량·비양수 셀·관측 공백·코드/명칭 충돌을 기록한다. 코드의 관측 유효기간은 공식 코드 효력기간이나 최초 공개시각의 증거가 아니다.

훈련만으로 고른 구분과 고정 지연값을 사용하고, 관측 없는 날짜는 결측/마스크로 남긴다. 미래 거래량으로 대표가격을 복원하거나 가격 정답을 전방 채우지 않는다. 최초 공표판을 복원하지 못하는 수정자료 후향 평가라는 한계는 기존 기준과 같다. V/T는 반복 열람한 개발 구간이다.

## 4. 외부 API 확인 범위

[15140583 정산 가격](https://www.data.go.kr/data/15140583/openapi.do)은 정산일·시장·법인 정보를 제공하며 포털 시간범위는 공란이다. 무료·이용허락범위 제한 없음 표시는 확인했지만 최초 조회일, 페이지 완전성, 원천 대체 가능성은 실응답으로 검증하지 않았다. 현재 경매 타깃을 정산가격으로 교체하지 않는다.

[15101609 관세청](https://www.data.go.kr/data/15101609/openapi.do)의 2026-08-20 수정 설명은 매월 15일경 정정·취하를 반영해 전월까지 현행화함을 명시한다. 중량은 순중량, 수입금액은 CIF 미화 기준이다. 포털에는 무료·이용허락범위 제한 없음·개발계정 10,000 트래픽이 표시돼 있다. 이는 과거 최초 공개판 복원이 아니며, 실제 공개 달력·HS 제품 상태·통화/단위 검증 전 모델 입력으로 연결하지 않는다. 이번 첫 비교에는 신규 API 수집이 없다. KREI 제외, KOSIS 허용을 유지한다.

실행은 `/tmp/agri-external-reference-v1-env/bin/python -m agri_data.external_reference_v1`의 `--stage preflight`, `--stage run-v`, 조건 통과 시 `--stage run-t` 순서다. T는 저장 V 평가와 입력·코드·환경 연결을 검증한다. 저장 모델을 다시 불러와 예측을 재생한 뒤에만 정답을 연결하며, 원천/모델 체크포인트 불일치는 조용히 재적합하지 않고 중단한다. 첫 사전검사는 실제 원천의 수집·페이지 완전성을 대조하는 CTE 때문에 시간이 걸릴 수 있다. 검증된 원천 집계 캐시가 만들어지면 학습 단계에서 전체 DB를 다시 추출하지 않는다.

## 8. 다음 질문 하나

후속 질문으로 **M5형 품목 내부 패널 학습**을 선택한다: “세부 가격 경로를 현재 대표가격의 입력 열로만 넣는 대신, 같은 품목의 보조 훈련 표본으로 함께 학습하면 대표가격 예측이 개선되는가?”

근거는 CAND_A의 추가 입력이 CTRL 대비 MAE를 낮췄으나 강한 기준을 넘지 못했고, 선택 경로 일부의 현재 관측 지원이 부족했다는 실제 결과다. 여러 세부 계열의 과거 유효 관측을 보조 훈련에 활용하는 학습 단위를 검토할 이유는 있지만, 이 방식이 공백 문제나 성능을 해결한다는 증거는 아직 없다. 동일 날짜 경계, 적합 시점 이전의 보조 정답, 계열별 정규화·가중치, 대표가격 직접 추출을 사전 고정해야 하며 세부 계열 수를 독립 날짜 증가로 세지 않는다. 새 외부정보·DLinear·결합비 탐색은 함께 넣지 않는다. 이번에는 질문 선택까지만 했고 CAND_B를 학습하지 않았다.
