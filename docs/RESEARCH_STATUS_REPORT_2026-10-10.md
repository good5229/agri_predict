# 농산물 가격예측 연구 현황 및 제안서 준비 보고서

최초 작성: 2026년 10월 10일 KST. 최종 보완: 2026년 10월 11일 KST. 이 문서는 현재까지의 개발·실험을 정리한 내부 보고서이며, 대회 제출용 10쪽 제안서 자체는 아니다. 판단의 기준 문서는 [PLAN.md](PLAN.md)이고, 아래 수치는 서로 다른 평가기간을 구분해 읽어야 한다.

2026년 10월 11일 보완: 외부 진단을 코드·기존 산출물과 대조해 설명을 정정하고 저장 예측 진단과 E106 후속 비교를 완료했다. **E106은 같은 7~9월 구간의 네 품목 MAPE를 E의 14.6500%에서 14.6126%로 낮춰 연구 후보로 보존했다. 통계적 우월성은 미확정이다.** 이어 요청한 직접 MLP16 한 후보는 4~6월 깐마늘 MAPE가 6.5810%에서 9.5029%로 악화해 중단했다. 저장된 은닉층의 출력층만 다시 맞춘 H는 8.4178%로 일부 회복했지만 E106보다 나빴다. R·M·H 대조의 30개 모두 훈련 손실은 R<H<M으로, 출력계수 변경의 회복과 현재 은닉표현에서 남은 격차를 확인했다(§12.7). 이후 R을 유지한 직교 잔차 보정 S도 MAPE 6.8227%·MAE 407.65원/kg으로 V의 가격 조건을 실패했다. 유의한 개선·악화는 확인되지 않았지만 사전 평균오차 조건에 따라 T를 실행하지 않고 이 표현 계열을 종료했다(§12.8). E106 전용 첫 실제 평가는 아직 미래 정답이 없어 `not_ready`이며, 다음 정상 발행의 모형 상태 보존을 기존 18시 점검에 연결했다. **현재 연구 기준은 E106이다.** 추가 결과는 §11~12에 기록하며, 아래 10월 10일 성능 수치·과거 판정은 변경하지 않았다.

## 1. 현재 결론과 남은 과제

**배추·무·양파·깐마늘의 향후 10일 가격을 발행할 수 있는 상태다.** 현재 시연용 구성은 가격이력 기반 직접 Ridge와 달력형 SARIMA를 50:50으로 결합한 `causal50`이다. 2026년 1~9월 후향 평가의 네 품목·10거리 동일가중 MAPE는 12.066%, MAE는 194.40원/kg이다. 같은 날짜의 직전가격 유지보다 낮지만, 구성모델인 Ridge와 SARIMA 각각에 대한 통계적 우월성은 입증되지 않았다. 이 수치는 전국 공식 타깃의 대회 점수나 실제 미래 성능이 아니다.

추가 실험에서 **배추의 조건부 추세 반응 보정**이 7~9월 후향 구간의 배추 MAPE를 19.3694%에서 19.1212%로 낮췄다. 네 품목 평균은 같은 구간에서 14.7121%에서 14.6500%로 낮아졌다. 작은 점추정 개선이며 유의한 우월성은 미확정이다. 이 후보를 보존한 뒤 역추세 예측을 더 축소해 보았으나, 배추·무 모두 악화해 추가 축소는 중단했다. 이후 깐마늘106 구성요소를 더한 E106을 보존했고 MLP16은 악화해 중단했다. **현재 비교 기준은 이전 개선을 함께 보존한 E106이며, 실패할 때마다 이전 개선을 폐기하지 않는다.**

현재의 가장 큰 제약은 실행 가능한 모델이 없다는 것이 아니다. 더 강한 가격이력 기준선에 대해 추가 변수·모델의 이득이 작거나 시기별로 뒤집히고, 같은 과거기간을 여러 번 살펴 독립적인 개선 증거가 부족하다는 점이다. 제안서에는 실제 예측 기능과 제한된 성능 근거를 제시하고, 아직 확인하지 못한 개선은 검증 계획으로 구분하는 것이 적절하다.

## 2. 데이터와 전처리

### 2.1 예측 대상과 원천의 역할

현재 핵심 실증은 확보된 **가락·강서 두 시장 거래의 경매가격을 원/kg으로 집계한 대리 목표**를 사용한다. 국내 도매시장 가격이라는 범위를 임의로 국내산만으로 좁히지 않으며, 품목·품종·등급·원산지·시장·법인·거래방식·포장·단위·거래일 정보를 보존한다. 이 대리 목표와 공식 전국가격 사이의 정의 차이는 아직 남아 있다.

| 자료 | 확보·사용 방식 | 현재 해석 |
|---|---|---|
| 두 시장 거래가격·금액·중량·거래행 수 | 다년 이력과 일일 수집, 핵심 가격 타깃 및 입력 | 현재 네 품목 시연의 중심 자료 |
| 전국 공개 가격·반입량 및 시장 패널 | 정의 대조, 선행성·잔차·직접모델 실험 | 별도 타깃 실험 결과를 두 시장 성적으로 합치지 않음 |
| KAMIS 도매 판매가격 | 다년 원응답 보존·단위 정규화 후 가격차·변화율 입력 시험 | 다른 거래단계의 정보. 경매 정답을 대체하지 않음 |

### 2.2 원천 보존과 일별 집계

1. **원응답을 보존한다.** 음수 조정거래, 원천 소수 문자열, null, 코드 이력과 수집 출처를 남긴다. 이상해 보인다는 이유만으로 원본을 수정하지 않는다.
2. **상태를 구분한다.** API 오류, 페이지 미완료, 빈 응답, 시장 휴장, 품목 무거래는 같은 결측이 아니다. 정상 완료 또는 정상 빈 응답으로 확인된 두 시장의 상태를 확인한 뒤 일별 대표값을 구성한다.
3. **가격은 거래의 단순 평균이 아니다.** 집계 대상 거래의 부호를 보존한 금액 합계와 순중량을 사용해 `가격 = 금액 합계 / 순중량`으로 원/kg을 계산한다. 원천 보존과 모델 입력 적격성은 별도다.
4. **모델에는 유효한 관측만 넣는다.** 가격과 중량이 양수인 관측 등을 모델별 적격 조건에 따라 사용한다. 비적격 원천을 없애거나 정답을 유리하게 수정하지 않는다.
5. **날짜를 무조건 채우지 않는다.** 휴장·무거래 날짜에 직전가격을 넣어 거래가 있었던 것처럼 만들지 않는다. 가격의 마지막 관측일, 경과일, 창별 관측 수·coverage를 함께 사용한다.

무의 2023-01-21 극소 거래량·극단 가격 사례에는 별도의 품질정책 실험을 했다. 선행 28개 관측일 중량 중앙값의 1% 미만이면서 가격도 선행 중앙값의 4배 이상 또는 1/4 이하인 날을 입력·훈련정답에서 격리하는 규칙이다. 최소 14개 선행 관측이 필요하며 평가 정답은 원래 값으로 유지했다. 이 규칙은 해당 사례를 본 뒤 정한 사후 탐색이고, 무의 별도 연구 발행에 적용한 이력이지 모든 실험에 자동 적용된 공통 전처리가 아니다. 개별 실험의 manifest와 설정을 따라야 한다.

### 2.3 예측시점의 정보 제한

현재 `causal50`에서 예측 원점을 `o`, 목표일을 `t=o+h`, 입력 cutoff를 `c=o−1일`로 둔다. 기준가격 `p0`는 cutoff까지 확보된 최신 유효가격이다. 원점 기준 마지막 가격이 14일을 넘게 오래됐으면 정상 예측 입력으로 인정하지 않는다. 모델 학습에서도 해당 적합 원점보다 앞선 목표일의 정답만 허용한다.

표준화는 매 학습의 훈련자료에서만 적합한다. 날짜의 요일·연중 위치는 목표일에 미리 알 수 있어 사용할 수 있지만, 미래 실제 기온·거래량·가격은 사용할 수 없다. 과거 예보도 당시 발행본과 가용시점을 확인해야 한다. 수정일, 경매시각 또는 관측일을 최초 공개시각의 증거로 쓰지 않는다.

과거 `fixed50` 일부 비교는 당일 가격을 이용하는 등 현재의 전일 cutoff와 정보집합이 달랐다. 따라서 옛 `fixed50`과 새 후보의 차이를 모델 구조만의 효과로 해석하지 않는다. `causal50`은 이 정보·갱신시점 문제를 맞춘 비교 기준이다. 다만 현재 내려받은 과거 수정본이 당시 공개본과 같다는 것까지 입증된 것은 아니다.

## 3. 작업 프로세스와 통계 판정

### 3.1 실험의 실행 순서

**실패 진단 → 반증 가능한 가설 → 프로토콜 고정 → 구현·검토 → 예측 저장 → 정답 연결·평가 → 보존 또는 중단**의 순서를 따른다.

| 단계 | 실제 작업 및 통제 |
|---|---|
| 실패 진단 | 품목·거리·월·가격 국면·관측 누락을 분해해 무엇이 잘못됐는지 확인 |
| 설계 고정 | 실패 기전, 새 정보 또는 제약, 최강 관련 기준선, 반증 조건, 중단 조건, 기간·거리·비교 가족을 결과 확인 전에 기록 |
| 구현 | Python 수집·검증·분석은 사용자 지정에 따라 Luna가 작성 |
| 코드 검토 | OCR가 대상 파일과 규칙을 결정하고 Astra가 선택 파일 전체 검토. 차단 문제 수정 후 변경 파일 재검토. 외부 LLM endpoint·새 credential 설정 없음 |
| 실행 | 입력 가용성·완전 페이지·체크포인트·제한 재시도·TLS·쿼터 준수. 오프라인 테스트는 개발 중 수행 가능 |
| 산출물 고정 | 입력·코드·선택 규칙·예측 파일의 출처와 해시 보존. 최근 실험은 정답 없는 manifest를 먼저 저장하고 재생성 대조 |
| 평가 | 같은 원점·목표일·품목·거리의 paired MAE/MAPE, 발행/정답/공통쌍 coverage, DM·HAC·Holm 평가 완료 |
| 연구 판단 | 작은 개선은 후보로 보존하되 우월성·운영 승격과 분리. 실패한 추가안은 중단하고 직전 개선안을 유지 |

로컬 Git 추적과 실제 수집·검증은 승인 범위다. 새로운 모델 학습 단계, 제출, 원격 저장소 생성·push는 해당 단계의 승인 범위를 따른다. 이 보고서 작성 과정에서는 새 학습·수집·제출을 실행하지 않았다.

### 3.2 성능의 계산과 해석

- **MAE:** 같은 정답 날짜에서 `평균 |예측−실제|`, 단위 원/kg. **MAPE:** 양수 정답에서 `100×평균(|예측−실제|/실제)`. 타깃 부재·비양수·후보 누락을 별도 기록한다.
- **평균 방법:** 현재 네 품목 요약은 품목 4개×거리 10개인 40셀을 동일가중한다. 표본이 많은 품목에 자동으로 더 큰 비중을 주는 전체 행 평균과 다르다. 품목 간 원/kg 수준 차이 때문에 전체 MAE만으로 성능을 판단하지 않는다.
- **검정:** 각 셀의 paired AE·APE 손실차에 양측 Diebold–Mariano 검정을 적용하고 실제 목표일 간격을 보존한 Bartlett HAC 9일을 주 분석, 28일을 민감도 분석으로 사용한다. 고정한 전체 가족에 각각 Holm 5% 보정을 적용한다.
- **표본:** 30쌍 미만은 정해 둔 실무 기준상 추론 불가다. 30쌍 이상도 점근 근사나 미래 일반화를 보장하지 않는다. 여러 거리의 예측칸을 독립 날짜처럼 세지 않는다.
- **판정:** 평균 개선과 유의 개선은 다르다. 비유의는 동등성의 증거가 아니다. 예측이 완전히 같아 손실차가 0인 경우, 사전 미선택, 표본 부족, 분산 부적합은 서로 다른 사유로 남긴다.

과거 실험별 Holm 가족 크기는 비교대상·품목·거리 수에 따라 다르다. 한 실험에서 보정했다고 해서 프로젝트 전체의 반복 탐색이 모두 통제된 것은 아니다. 이미 본 후향기간의 연속 개발 결과를 새로운 독립 확증으로 부르지 않는다. 초기의 엄격한 최소 개선폭·유의성 문턱에서 탈락한 과거 결과는 그대로 보존하되, 현재의 시연·후보 보존 단계에는 그 문턱을 소급해 필수조건으로 추가하지 않는다.

## 5. 모델·하이퍼파라미터와 갱신 방식

### 5.1 현재 시연 기준선과 보존 후보

| 구성 | 설정 | 학습·예측 방식 |
|---|---|---|
| 직접 Ridge | `StandardScaler`, `Ridge(alpha=10, fit_intercept=True)`, 기본40, 로그 가격비 목표 | 품목×h별 별도 모델. 2014년 이후 가용 이력을 확장 사용, 월 첫 적격 원점에 재적합, 최소 훈련정답 90개 |
| 달력형 SARIMA | 로그가격, `(1,1,1)×(1,0,0,7)`, `trend='n'`, 최근 730달력일, `maxiter=100`, 정상성·가역성 강제 | 월별 적합 후 일별 상태 갱신. 결측은 NaN으로 유지. 마지막 입력 o−1에서 목표 o+h까지 h+1단계 예측 |
| `causal50` | `0.5×Ridge가격 + 0.5×SARIMA가격` | 가격 단위 산술평균. 정보 cutoff와 갱신시점을 맞춘 결합 |
| 직전가격 유지 | `예측=p0` | 핵심 무학습 기준선 |
| 보존 후보 E | 배추 h=4~10에서 `p0×exp(s×log(causal50/p0))` | 7일·28일 추세 일치 s=1.25, 불일치 s=0.75. 추세 영값·자료 부재 등은 보정하지 않음. 배추 h=1~3과 다른 세 품목은 `causal50` 유지 |

결합 구성요소가 유효하지 않을 때의 fallback·발행 보류와 그 사유도 기록한다. SARIMA 실패 시 유효한 직접 Ridge로 돌아갈 수 있지만, 필요한 직접 예측 자체가 없으면 정상 결합 예측으로 위장하지 않는다. 현재 시연 실행 환경은 scikit-learn 1.3.0, statsmodels 0.14.0이며, 신경망·강건 특징 등 일부 실험은 별도 가상환경을 사용했다. 모든 실험이 동일 라이브러리 버전이었다고 가정하지 않는다.

|---|---:|---|---|
| 배추 | 100 | X4 | R2 |
| 무 | 1,000 | X1 | R2 |
| 양파 | 1,000 | X1 | R2 |
| 깐마늘 | 1,000 | X1 | R1 |

별도 전향 실험의 양파는 시장별·총량별 기본40 직접 Ridge(alpha=10, 최소 90개 정답), 최근 28달력일 가락 중량비 중앙값(양시장 동시 양수 관측 최소 5개, 최신 14일)을 이용한 재조합과 fallback을 쓴다. 깐마늘은 거리 1~10 pooled Ridge(alpha=10)와 직전가격을 결합하며 Ridge 가중치는 h=3·4에서 1, 나머지에서 0.75다. 이 설정을 네 품목 `causal50`과 혼동하지 않는다.

### 6.3 가장 최근 추가 실험: 역추세 예측 축소는 중단

관측 7일·28일 추세가 일치하는데 E가 반대로 움직이면 로그 변화폭을 절반으로 줄이는 단일 후보를 시험했다. 확인 구간에서 배추 MAPE는 15.5366→16.0498%, MAE는 87.80→91.50원/kg, 무 MAPE는 12.7855→12.9926%, MAE는 68.33→69.30원/kg로 모두 악화했다. 네 품목 평균 MAPE도 12.1643→12.3444%로 높아졌다.

발행 3,020개와 공통쌍 2,571개를 보존했다. 고정40검정에서 유의 개선은 없었고, HAC28에서만 배추 h=8 AE의 유의 악화 1개가 있었다(Holm p=0.00581; HAC9에서는 비유의). 두 품목 모두 실용 확인 조건을 통과하지 못해 **7~9월 후보 생성·채점은 하지 않았다.**

배추에서 관측 추세와 충돌한 E의 방향 오류율은 35.0%, 비충돌은 44.1%였고, 무는 각각 29.0%, 36.8%였다. 이는 ‘최근 추세와 충돌하면 방향 오류일 가능성이 더 높다’는 가설에 반대되는 증거다. 다만 축소는 예측 방향을 그대로 두고 변화폭만 줄이므로, 방향 적중률만으로 MAE/MAPE 악화의 원인을 설명할 수 없다. 방향을 맞힌 경우에도 변화폭을 과대 예측했다면 축소가 유리하고, 과소 예측했다면 불리할 수 있다. 활성 행의 변화폭 과대·과소와 이득·손해 크기를 분해할 필요가 있다. 중단 근거는 확인기간의 실제 두 손실 악화이며, **E를 유지하고 같은 조건의 축소율·창 재탐색은 중단한다.**

### 6.4 실제 미래 발행과 전향 검증

네 품목 40개 예측은 10월 10일 14:50 KST에 발행됐다. 당시 입력은 10월 8일까지의 자료이며 마지막 가격일은 배추·무·양파 10월 8일, 깐마늘 10월 7일이다. 목표일은 10월 11~20일이므로 발행 완료와 미래 정확도 확인을 구분한다. [예측 CSV](../outputs/experiments/four-crop-forecast-20261010/forecast.csv), [예측 JSON](../outputs/experiments/four-crop-forecast-20261010/forecast.json), [시연 화면](../outputs/experiments/four-crop-forecast-20261010/index.html)을 보존한다.

양파·깐마늘의 별도 전향 평가는 10월 7~10일의 12개 발행 산출물을 검사했으나, 10월 10일 기준 양파 h=1의 2쌍과 h=2의 1쌍만 정답과 연결됐다. 나머지 거리는 0쌍이다. 고정8/32/40검정 가족 모두 최소 30쌍에 미달하며, 1~10일 전체를 같은 발행일로 묶은 완결 코호트도 0/30이다. **전체 전향 MAPE는 아직 산출·주장할 수 없다.** 세 쌍의 점수로 미래 성능을 대표하지 않는다. 근거: [10월 10일 전향 평가](../outputs/assessments/two-crop-2026-10-10.json).

10월 11일 코드 확인 결과, 기존 양파 완결 코호트는 단순히 10일째 만기를 기다리는 지표가 아니라 **열 목표일 모두 발행·양수 정답이 있는 완전사례**다. 중간에 정상적으로 양수 거래가격이 없는 날이 있다면 시간이 지나도 그 발행일은 포함되지 않는다. `mature` 자체는 정답 스냅숏 범위로 별도 계산되므로 만기 구현 오류와 구분한다. 기존 지표를 보존하면서, 만기가 지난 발행일에서 실제 관측 가능한 정답을 거리별로 평가하는 보조 요약을 추가하기로 했다. 양수 정답이 없다는 사실만으로 시장휴장·품목무거래를 구별할 수는 없다.

| XGBoost·RandomForest·변수선택 | 확장71과 선택을 사용해도 기준선 대체 근거 부족 | 기본40을 다른 표현으로 교체한 효과와 모델 효과가 섞임. 이후 보존106 실험의 근거가 됨 ([변수선택](../agri_data/full_history_feature_selection_eval.py)) |

LSTM·TCN·Transformer 등의 대형 시계열 신경망은 여기서 완료된 실험 결과로 제시하지 않는다. ‘신경망까지 모두 해 보았으나 실패했다’는 요약은 부정확하다.

MLP의 순서 교란은 모든 표본에 같은 열 순열을 적용한 것이 아니다. 품목·원점별 해시로 다른 순열을 만들고, 관측 마스크·기준가격·지연 기준점·기울기 끝점과 기본106 값 전체를 보존한 채 같은 요약창 소속의 가격값만 교란했다. 따라서 이미 보존된 시간 구조 외의 **잔여 순서 정보**를 시험한 대조다. 요약형은 경로값과 마스크를 함께 제거하므로 순서형 대 요약형만으로 순서 효과를 분리하지 않는다. 실제 실행 환경은 scikit-learn 1.9.1이며, 저장 적합 기록은 반복 수·최종 훈련손실·경고만 포함한다. 경고만을 이유로 epoch를 늘리지 않는다.

## 8. 반복 실패에서 얻은 판단

**첫째, 비교 기준이 바뀌었다.** 초기에는 직접 Ridge나 직전가격만 넘으면 개선처럼 보였지만, 현재는 동일정보의 Ridge/SARIMA 결합과 보존안 E가 더 적절한 대조군이다. 약한 기준선을 이긴 실험을 새 기준선에 대한 성공으로 재활용할 수 없다.

**둘째, 특징 수 증가와 정보 증가는 다르다.** 가격·물량의 다른 요약은 이미 있는 정보와 중복될 수 있다. 기본40을 없앤 뒤 확장71로 바꾸면 표현 손실이 생길 수도 있다. 보존106에서 깐마늘의 작은 긍정 신호가 나온 것은 기존 유용한 표현을 유지할 이유가 된다.

**셋째, 관계가 시간에 따라 바뀐다.** 전국 물량·가격추세의 관계 부호가 바뀌었고, 튜닝의 전년도 이득이 다음 해 유지되지 않았다. 국면변화가 원인이라는 가설은 합리적이지만, 그 국면을 예측시점에 안정적으로 구분하는 규칙은 아직 입증하지 못했다.

**넷째, 방향과 변화폭은 구분해야 한다.** 최근 추세와 충돌하는 예측이 방향을 더 자주 틀린다는 근거는 없었고, 그 변화폭을 일괄 축소한 후보의 손실은 악화했다. 다만 손해가 방향 적중·과소반응 사건에서 얼마나 발생했는지는 별도 기여 분석이 필요하다. 사전 구분 근거 없이 축소를 더 강하게 하는 방식은 중단한다.

**다섯째, 유의성·coverage·표본은 서로 다른 문제다.** 마늘의 일부 후보는 평균이 좋아도 통계적 확신이 약하고, 건고추의 일부 후보는 입력·정답 지원 자체가 약하다. 전향 검증은 아직 결과가 나쁠 단계가 아니라 결과를 판단할 표본이 없는 단계다.

**여섯째, 설명 기능과 예측 향상을 구분해야 한다.** 날씨·산지·거래구성은 사용자에게 맥락을 줄 수 있지만, 그것이 점예측 오차를 낮췄다는 주장은 별도 실증을 요구한다. 화면 완성도나 코드 검토 통과를 정확도 개선의 대용으로 삼지 않는다.

## 9. 향후 실험 전개 제안: 제안서 통과를 위한 우선순위

이 절은10월10일 제안을 보존한 기록이다.10월11일 후속 실행과 현재 작업 상태는 §11~12를 따른다.

### 9.1 우선 유지할 산출물

현재의 네 품목 10일 예측과 `causal50`, 보존안 E, 깐마늘 보존106·경로 MLP의 탐색 결과, 별도 전향 발행 이력을 모두 유지한다. 추가 실험은 이 결과 위에 쌓는다. 점예측 성능 향상이 목표이며 새 보고서·테스트 수·검토 통과를 그 성과로 바꾸어 제시하지 않는다.

제안서 전까지 모든 품목·거리의 유의 우월성을 얻거나 최소 30쌍의 전향 표본을 채우는 것은 현실적인 전제조건이 아니다. 단기 시연과 장기 전향 검증을 병행하고, 이미 발행한 예측을 고치지 않아 실제 정답이 도착한 뒤 평가할 수 있게 한다.

### 9.2 제안하는 다음 작업과 중단 조건

다음은 **제안**이며 이번 보고서에서 실행한 실험이 아니다. 새로운 적합은 단계 승인과 실행 전 고정을 거친다.

| 우선순위·작업 | 실패 기전과 새 정보·제약 | 비교·반증·중단 규칙 |
|---|---|---|
| 1. E의 미래 비교 발행 | 후향의 작은 개선이 실제 미래에도 유지되는지 미확인. 새 정보는 앞으로 도착할 미열람 정답 | 새 발행일부터 E와 causal50을 같은 cutoff·키로 고정. 과거 40개를 덮어쓰지 않음. paired 두 손실·coverage·HAC/Holm 평가. 평균 악화나 coverage 손실을 숨기지 않고 개선 미확정 상태를 유지 |
| 2. 깐마늘 보존106·MLP의 제한 진단 | 보존106은 직접모델에서 악화·동일SARIMA 결합에서 개선. MLP는 세 표현 모두 긍정 신호가 있어 순서만의 효과로 보기 어려움 | 완료된 구성요소 교체 비교를 반복하지 않고 저장 예측의 큰오차·개선 기여·상쇄를 분석. MLP 경고와 교란 설계는 확인 완료했으며, 새로운 진단 근거가 있을 때만 하나의 질문을 검증하는 후속 설계 |
| 3. 기존 예측의 반전 성공/실패 분석 | 관측 추세와 충돌한다는 규칙이 오류를 식별하지 못함 | 미래 정답을 쓰지 않고 계산 가능한 기존 가격 경로·기준모델 간 차이가 훈련 블록에서 반복적으로 구분하는지 먼저 확인. 구분이 없으면 적합하지 않음. 축소율·창만 바꾸는 재시도 금지 |
| 4. 공식 타깃·순별 집계 연결 | 지금의 두 시장·10일 실증과 대회 전국·2순/3순 요구 사이에 간극 | 공식 제공 타깃·산식 확인 후 어댑터와 동일정의 평가 설계. 2순을 20일 뒤 하루 가격으로 대신하지 않음. 제공 조건 미확정 부분은 확장 계획으로 명시 |

MLP 후속을 한다면 ‘epoch나 층을 늘리면 좋아질 것’이라는 가정만으로 넓은 탐색을 시작하지 않는다. 현재 수렴 경고가 실제 최적화 부족인지, 개선이 경로 순서에서 왔는지 먼저 구분한다. 같은 과거 시험기간을 다시 사용한 결과는 후향 개발로 표시하고, 새로운 독립 검증이라고 이름만 바꾸지 않는다. 깐마늘에 한정한 bounded trial에서도 개선이 없으면 그 방향은 멈추고 기존 후보를 보존한다.

배추·무의 최근 실패를 이유로 새 시장 확보를 요구하거나 즉시 대형 신경망 탐색으로 옮길 근거는 없다. KAMIS·기상 변수 역시 이미 실패한 동일 표현을 반복 추가하기보다, 새로 확인된 시차·가용성·대표성 근거가 생겼을 때만 재검토한다. 건고추는 현재 사용자 범위에 따라 보류한다.

### 9.3 제안서의 중심 주장

추천 주제는 **“가격이력 기반 농산물 단기 전망과 예측 근거·가용성 공개 대시보드”**다. 핵심은 사용자가 품목별 현재 가격과 향후 흐름을 보고, 어느 날짜의 자료로 만들어졌는지와 과거 오차가 어느 정도였는지를 함께 이해하도록 하는 것이다.

| 제출 본문 | 제시할 내용 | 이미 있는 근거 / 남은 작업 |
|---|---|---|
| ① 예측아이디어 | 직접 Ridge와 달력형 SARIMA 결합, 품목별 추가 보정, 시간순 비교·전향 축적 | 네 품목 40개 발행, 후향 비교, 배추 보정 후보. 공식 5품목·순별 확장은 계획으로 분리 |
| ② 구현 데이터 | 실제 원천, 금액/중량 집계, 결측상태, 전일 cutoff, 변수와 가용시점 | 수집·정합성·출처·해시가 존재. 공식 타깃과 두 시장 대리 목표의 차이 명시 |
| ③ 활용안 | 과거/미래 가격, 기준일, 품목·거리별 오차, 데이터 지연 표시, 설명 자료 | 실제 시연 산출물 사용. 설명 변수를 인과효과나 오차개선으로 과장하지 않음 |

제안서에 사용할 수 있는 성능 표현은 다음 수준이다.

## 11. 10월11일 후속 완료: 작은 개선의 결합과 실패 원인 확인

### 11.1 배추 개선을 유지한 깐마늘 결합 후보 E106

사용자의 후속 실험 승인에 따라, 기존 배추 조건부 보정을 포함한 E를 유지하면서 **깐마늘만 보존106과 동일 SARIMA의 50:50 결합으로 바꾼 단일 후보 E106**을 비교했다. 새 학습·특징·가중치 탐색은 없었다. 같은 cutoff·월별 적합·기준 구성요소·발행키를 대조하고, 확인 구간을 통과한 뒤에만 후속 구간을 채점했다. Python은 Luna 작성·Astra OCR 전체 검토 후 실행했다.

| 구간·동일가중 대상 | E MAPE(%) | E106 MAPE(%) | E MAE(원/kg) | E106 MAE(원/kg) |
|---|---:|---:|---:|---:|
| 확인: 4월1일~6월20일, 깐마늘10거리 | 6.7681 | 6.5810 | 410.08 | 396.54 |
| 확인: 같은 기간, 네 품목40셀 | 12.1643 | 12.1176 | 160.65 | 157.27 |

확인 원점은4월1일 이상, 후속 원점은7월1일 이상이다. 확인은 발행3,020/3,020키·공통정답2,571쌍을 유지했고, 깐마늘은618쌍·거리별58~65쌍이었다. 후속도3,160/3,160키·공통정답2,470쌍을 유지했으며, 깐마늘은540쌍·거리별54개 고유 목표일이었다. 다른 품목의 후속 거리별 표본은 배추64·무65·양파64개다. 여러 거리의 같은 목표일은 독립 관측으로 세지 않는다.

E 대비 후속 네 품목 MAPE 추가 이득은 **0.0375%p**, MAE는 **3.93원/kg**이다. 같은 기간 causal50의14.7121%·286.05원/kg과 비교하면, 배추 보정과 깐마늘 결합을 함께 보존한 총 차이는 **−0.0995%p·−4.23원/kg**이다. 이 결과를 1~9월 기본 성적12.066%와 직접 연결해 개선율을 계산하지 않는다.

손해가 사라진 것은 아니다. 확인에서는 깐마늘3일이 MAPE+0.0922%p·MAE+3.56원/kg 악화했다. 후속에서는1일이+0.0048%p·+2.67원/kg,6일은 MAPE만+0.0128%p 악화했다. 월별10거리 평균은 확인4·5·6월과 후속7·8·9월 모두 두 손실이 낮았고, 후속 월별 MAPE 차이는 각각−0.1073·−0.2494·−0.0555%p였다. 이 진단으로 유리한 거리만 다시 선택하지 않았다.

**통계평가는 완료했으나 우월성은 미확정이다.** 단계마다 깐마늘10거리×AE/APE의 고정20검정에 목표일 달력 DM/HAC9·HAC28와 각각 Holm5%를 적용했다. 확인의 주 분석HAC9는 유의 개선·악화0개였고, HAC28만8·10일의 두 손실 모두 유의 개선이었다. 후속은 두 대역 모두20검정 중 유의 개선·악화0개로,10거리 모두 미확정이다. 비유의는 동등성을 뜻하지 않는다. 이미 반복 열람한 후향 자료의 재조합이며 독립 확증도 아니다.

사전의 두 평균손실 개선·발행범위 보존 조건을 충족해 **E106을 다음 연구 후보로 보존**한다. 기존 E·causal50·미래 발행은 유지하고 운영 교체는 하지 않았다. 이전 보존106의 엄격한 채택 실패도 소급 변경하지 않는다. 근거: [확인 평가](../outputs/experiments/preserved-improvement-composition-20261011/confirmation-report.json), [후속 평가](../outputs/experiments/preserved-improvement-composition-20261011/final-report.json).

### 11.2 진단으로 확인한 것과 남은 한계

**역추세 축소의 손해는 변화폭으로 설명된다.** 확인 구간에서 실제로 바뀐 공통쌍547개 중254개는 좋아졌고293개는 나빠졌다. 기존 E가 반전 방향을 맞혔지만 변화폭을 이미 과소예측한271개는 축소 후 모두 악화했고, 네 품목 가중 MAPE 손해0.6053%p 중0.5669%p를 차지했다. 반대로 방향이 틀린184개는 모두 개선됐다. 전체 이득0.4252%p보다 손해가 커 순악화0.1801%p가 됐다. 따라서 방향 정확도만으로 앞선 실패를 설명하거나 같은 조건의 축소율만 다시 탐색하지 않는다.

**기존 작은 개선은 한 주·한 달만의 결과는 아니지만 불확실하다.** E의7~9월 MAPE 차이는 한 달씩 제외해도−0.0780~−0.0398%p, 한 ISO주씩 제외해도−0.0948~−0.0246%p로 개선 방향을 유지했다. 다만29주의 기여가 전체 순개선의 약64%였으며, E 확인 구간에서는 제외 기간에 따라 부호가 바뀌었다. 깐마늘106결합의1~9월 개선도 한 달·한 주 제외에 부호가 유지됐지만, causal50의 큰오차 상위10% 사건에서는 MAPE 이득이 없었다. 이득은 주로 나머지 관측에서 나왔다.

목표일을 함께 재표집한14·28일 순환블록 bootstrap 각2,000회에서, 기존 E·깐마늘106의 확인/후속 MAE·MAPE에 대한 **16개 보조95% 구간 모두0을 포함**했다. 예컨대 E 후속 MAPE 차이의14일 구간은[−0.1895,+0.0739]%p다. 이는 기존 후보의 후향 민감도이며, 이번 E106 재조합의 신뢰구간이나 새 유의성 판정으로 대신 사용하지 않는다.

**실제 발행과 후향 자료의 신선도가 달랐다.** 2026년 저장 후향 예측은 최신 양수 가격이 원점1일 전인 비중이80.7%였지만,10월10일 실제40개 예측은75%가2일 전·25%가3~4일 전이었다. 최근28일 양수 관측도 평균22.59일 대19.25일이었다. 단 한 번의 발행 비교이고, 최초 공개 시각을 관측일로 추정할 수 없으므로 이를 불필요한 지연의 증거로 단정하지 않는다.

**단순 결합의 한계도 보인다.** Ridge와 SARIMA의 공통8,496쌍에서 실제값이 두 예측 사이인 비율은11.4%였다. 품목별 같은 방향 오차 비중은85.2~90.6%로 높았다. 정답을 보고 구성요소를 고르는 최선값은 실행할 수 없는 진단이며, 미래에 어느 모델을 택할지 구분하는 근거를 얻은 것은 아니다. MLP는 저장 학습·검증곡선이 없어 반복 제한 경고만으로 최적화 부족을 판정할 수 없었다. 추가 층·epoch·가중치의 넓은 탐색은 시작하지 않았다. [상세 진단](../outputs/experiments/research-progress-diagnostic-20261011/report.json)에 기여·기간 제외·입력 나이·구성요소 결과를 보존했다.

**가장 이른 최초 추론 검토는2026년11월30일**이다. 실제 최소표본 확보가 늦으면 더 늦어진다. 최초 준비일과 검토 시도를 불변 기록으로 고정해 월말 소급 검토·중복 검정·유의해질 때까지의 반복 검정을 막는다. 주 가족은 **E106−E 깐마늘10거리×AE/APE의20검정**, 달력HAC9·HAC28 각각Holm5%다. 주 효과는10거리 동일가중 MAPE 차이이며 MAE·coverage를 함께 본다. 배추 E−causal50과 네 품목40셀 E106−causal50은 보조 평균·구간만 공개한다. 정식 검토의 주·보조 평균차 구간은 같은 만기 코호트에서 목표일을 공동 재표집하는14/28일 블록·각2,000회로 고정했다. 현재 연결 기능의 완성과 E106의 미래 정확도 입증을 구분한다.

### 12.6 다음 정상 발행부터 모형 상태 보존

기존 발행 정책을 유지하면서 실제 적합·갱신 때 상태를 기록하도록 발행기를 보완했다. Ridge40의40개와 깐마늘 Ridge106의10개를 서로 다른모형 ID로 구별해 계수·절편·fitted scaler·특징순서·훈련키 해시·행수·최대 입력/정답 날짜를 남긴다. SARIMA는 네 품목의 월초 갱신 전 체크포인트, 파라미터·모델/필터/초기화 설정·달력 인덱스·상태/공분산, 이후 날짜별 갱신 입력과 상태를 남긴다. 결측 날짜는 결측으로 유지하며 체크포인트보다 이른 상태를 요구하면 이용 불가로 처리한다.

상태는 각 발행 디렉터리의 `model-state.json`에 기록하고 `forecast.json`의 경로·해시, 일별 claim/terminal, 원천·코드·실행 환경과 연결한다. 전체 원천 DB를 복제하지 않는다. Luna 작성·Astra 전체 검토를 마쳤으며, 합성 자료에서 원래 훈련열을 다시 적합하거나 재필터링하지 않고 저장 체크포인트와 결측일 입력만으로 갱신 예측을 복원했다. 기존 예측 정책과 실패/복귀 처리는 유지한다.

기존18시 **농산물 예측 성능·제출본 점검**에 정식 발행 기록·상태 저장·E106 전용 평가와 고정20검정 규칙을 반영했다. 첫10월11일 발행을 다시 적합하지 않았으므로 **실제 상태 산출은 다음 정상10월12일 발행부터이며, 실제 저장 상태의 재현은 아직 미검증**이다. 준비 기능을 구현한 것을 지연 내성이나 정확도 개선으로 부르지 않는다. 과거 지연B는 보류를 유지하고, 새로운 정보 가림 예측·후보 적합은 이번에 실행하지 않았다.

### 12.7 R·M·H 단회 대조 완료와 H 중단

**출력층 변경으로 M의 오차는 일부 회복됐지만 E106에는 미치지 못했다. H를 V에서 중단하고 E106을 유지한다.** V는 목표2026년4월1일~6월20일·원점4월1일 이상이다. 사전에 고정한30개 저장 M·동일 훈련행·scaler로 R과 H를 각30회 적합했고, 새 은닉층 학습은0회였다. 정답을 붙이지 않은 전체 예측을 저장한 뒤 한 번 채점했다. 기존 원천·예측은 보존했다.

같은 훈련행의 적합별 순수 로그비 MSE를30개 적합에 동일가중한 값은 **R 0.05012280, M 0.06159242, H 0.05638469**였다. 출력계수 변경으로 회복한 차이 `L_M−L_H`는 **0.00520774**, 현재 은닉표현에서 남은 R 대비 차이 `L_H−L_R`는 **0.00626189**다.30개 모두 `L_R<L_H<L_M`이었다. 따라서 현재 출력계수 선택이 훈련 격차에 기여한다는 설명은 지지되지만, 출력계수만 다시 맞추면 R의 훈련 적합에 도달한다는 설명은 지지되지 않는다. 이 차이를 원인 백분율이나 가격 MAPE의 인과 기여율로 환산하지 않는다. 최적화·규제의 별도 기여, 초기화·분포 변화는 이번 대조만으로 확정하지 않는다.

### 12.8 R을 유지한 직교 잔차 보정 S: V 실패와 계열 종료

**S도 V의 평균 가격오차 조건을 통과하지 못했다. T는 실행하지 않았으며, 현재 고정 은닉표현을 이용한 이 계열을 종료하고 E106을 유지한다.** 이것은 통계적으로 유의한 악화를 입증했다는 뜻이 아니다. 진행 조건은 사전에 고정한 결합 MAPE 개선·MAE 비악화·발행 범위 유지·수치 검산이었고, 그중 가격 조건 두 가지를 실패했다.

이번 후보는 H와 달리 기존 R106의 계수·절편을 유지했다. 각 적합의 같은 훈련행·scaler·저장 은닉층으로 `A=[1,X]`, `Z=ReLU(XW1+b1)`를 만들고, 훈련 선형공간 성분을 제거한 `Zperp=Z−AB`에 R의 잔차를 벌점 없는 SVD 최소제곱으로 한 번 회귀했다. 새 절편은 두지 않았으며 검증에는 훈련에서 얻은 B·gamma만 적용했다. 외부 정보를 추가한 실험이나 검증 모집단에서의 직교성을 보장하는 실험은 아니다. Luna 작성·Astra OCR 전체 검토와 차단 수정 재검토 후 실행했다.

V는 목표 2026년 4월 1일~6월 20일, 원점 4월 1일 이상이다. **B·gamma 계산은 각각 30회, 새 R·M·H 적합은 모두 0회**였다. 훈련행 1,613~1,670개와 저장 상태의 출처를 확인했다. 전체 3,020개 예측을 정답 없이 불변 저장한 뒤 저장 계수·원천을 이용한 무재적합 재현 검증과 채점을 완료했다. 깐마늘 755개 모두 S를 사용했고 추가 복귀·보류·누락은 0개였다. 공통 양수 정답은 네 품목 2,571쌍, 깐마늘 618쌍이다. 깐마늘의 고유 목표일은 65일, 거리별 58~65일이며 공통쌍의 고유 원점은 80일이다. 겹치는 거리별 예측을 독립 일자로 세지 않는다. 정답이 없는 깐마늘 137개 발행도 coverage에 남겼다.

**훈련에서는 추가 적합 기여가 있었다.** A의 수치 rank는 87~91, 직교 잔차 Zperp의 rank는 30개 모두 16이었다. 전체 보정이 0인 경우는 아니었다. 적합별 동일가중 로그비 MSE는 R **0.05012280**, S **0.04768183**, 차이 **−0.00244096**이며 모든 적합에서 감소했다. 이는 훈련 내부의 기술 진단이다. 겹치는 훈련행·적합을 독립 추론 표본으로 취급하지 않으며, 훈련 감소는 독립 예측신호를 입증하지 않는다.

### 12.9 무 예측거리 계수 공유 RHS: V·T 통과, 후향 후보 보존

**C는 V와 T의 사전 가격·coverage 조건을 모두 통과해 E106-RHS를 후향 개선 후보로 보존한다. 운영 E106은 유지한다.** 무 10거리 동일가중 결합 MAPE 차이는 V −0.002764%p, T −0.016478%p이며 개선 폭은 작다. T의 14/28일 블록 평균차 구간은 모두 0보다 낮지만, 거리별 주 분석인 HAC9·고정60검정 Holm에서는 유의한 셀이 없었다. 평균 추론과 거리별 다중검정을 구분하며 실제 인접 순서의 독자적 우월성이나 미래 효과를 확정하지 않는다. 같은 입력·시간조건·SARIMA를 유지하고 무의 직접 Ridge만 변경했다. B는 기존 독립 Ridge, D는 추가 대각 축소, C는 실제 인접 경로, P는 순서 변경 경로다. 후보는 C 하나이며 D/P로 교체하지 않는다. 배추 E 보정·깐마늘106 결합·양파 구성은 E106 그대로 보존했다.

V는 목표 2026년 4월 1일~6월 20일·원점 4월 1일 이상이다. 원래 월별 훈련행과 각 거리의 scaler를 유지해 B 30개 계수와 D/C/P 9개 공동모형을 계산했다. 추가 SARIMA 적합은 0회다. 실제 훈련행은 거리·월별 3,734~3,793개, 최신 훈련 정답은 각각 3월31일·4월30일·5월30일이었다. 정답 없는 예측을 먼저 저장했고, 다른 세 품목의 E106 예측과 정보시점·저장계수·CSV 연결을 무재적합 검증한 뒤 채점했다. 전체 저장 격자는 3,240키이며 그중 원점 조건을 만족한 평가 대상은 3,020키다. 무 755키 모두 발행·변경됐고, 추가 누락·복귀·보류는 0개다. 양수 정답 공통쌍은 무 651개, 고유 목표일 69일·각 거리 61~69일, 고유 원점 80일이다.
