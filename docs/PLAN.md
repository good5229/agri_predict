# 농산물 경락가 예측·설명 대시보드 기획안

작성일: 2026-09-28 KST. 상태: **기획 합의 완료, 데이터 본수집·정합성 검증 착수**.

이 문서는 사용자와 합의한 연구·제품 기획이다. 모델 성능이나 데이터 완전성이 입증됐다는 뜻은 아니다. 확인되지 않은 데이터 속성은 실행 과정의 검증 항목으로 남기며 기존 합의를 다시 선택할 문제로 돌리지 않는다. 첨부 신청서와 작성 예시는 형식 참고자료이며 사용자 지시와 구별한다.

## 1. 목표와 심사기준

[2026 AI 농산물 가격예측 온라인 해커톤](https://hackathon.imaginationgroup.co.kr/nongnet)에 지원하기 위해 실현 가능한 예측 방식과 활용안을 설계한다. 연구 결과를 바탕으로 누구나 가격 전망과 배경을 이해할 수 있는 대시보드를 만든다. 특정 조직 담당자 인터뷰를 선행조건으로 두지 않는다.

| 예선 심사기준 | 기획에서 제시할 근거 |
|---|---|
| 실제 구현·활용 가능성 | 승인된 API, 실제 수집 자료, 재개 가능한 수집 방식, 미래정보를 차단한 실험, 운영 가능한 최종 예측 구성 |
| 데이터와 아이디어의 연결성 | 각 변수가 가격 예측에 기여한다는 가설, 공개 시차, 가공 방법, 변수 제거 비교 및 실제 평가 결과 |
| 활용 대상·활용 방안의 명확성 | 통계에 익숙하지 않은 사용자도 품목별 과거·미래 가격, 변동 배경, 선택형 예상 범위를 이해하는 화면 |

본선은 공개된 5품목 평균 오차율과 회차 동일 비중을 따른다. 공식 산식·타깃·재현 규칙을 우선하며 자체 MAPE를 공식 점수와 같다고 단정하지 않는다. 사용자 제공 제출 조건은 PDF/DOCX 1개, A4 10쪽 이내, 운영자 안내·예시 삭제, 본문 ① 예측아이디어 ② 구현 데이터 ③ 활용안이다. 제출 마감은 2026-10-18 23:59 KST. 일정 압박을 이유로 검증에 성공했다고 꾸미거나 자동 제출하지 않는다.

## 2. 예측 대상과 가격 정의

- 대상은 **배추·무·양파·깐마늘·건고추의 국내 도매시장 경락가**다. 국내 시장이라는 뜻을 국내산만으로 바꾸지 않는다.
- 단기는 향후 10일의 일별 예측, 중기는 2순·3순 후 예측이다. 순별 경계·대표가격·휴장일 평가 방식은 공식 정의대로 구현한다. 2순을 임의로 20일 뒤 단일가격으로 치환하지 않는다.
- 시장·법인·품종·등급·원산지·거래방식·포장·단위·낙찰일·정산일을 보존하고, 공식 타깃에 포함되는 거래와 산식으로 집계한다. 정가수의를 임의 포함하거나 제외해 공식 타깃을 바꾸지 않는다.
- 정산 `avgprc`의 단순 재평균을 피한다. 총금액/총중량 방식과 낙찰가×수량 방식은 실제 응답에서 다를 수 있으므로 원천과 정산을 대조한다. 공식 타깃 산식이 최종 기준이다.
- 원천자료에 음수·취소/정정 의심 행이 있어도 자동 삭제·절댓값 변환하지 않는다. 비양수 순중량으로 가격을 계산하지 않는다.
- 확인된 휴장의 표시가격은 직전 장 마감값으로 연결한다. 품목 무거래·API 실패·정산 미완료를 휴장으로 간주하지 않으며 거래량은 전일 값으로 채우지 않는다. 보간 여부와 마지막 실제 거래일을 남긴다.

## 3. 데이터와 수집기간

**품목별로 신뢰성을 유지하면서 확보 가능한 가장 긴 기간을 수집한다. 10년은 필수조건도 상한도 아니다.** 품목과 외부변수의 시작일을 다르게 허용한다. 짧은 외부자료 때문에 오래된 가격자료를 버리지 않는다. 최대 수집기간과 최적 모델 학습기간은 서로 다르다.

| 자료 | 예측·설명에 사용할 후보 정보 | 출처 |
|---|---|---|
| 원천 거래·정산 | 가격 수준·추세·변동성, 거래물량, 시장·등급·산지 구성 변화 | [aT 원천](https://www.data.go.kr/data/15141810/openapi.do), [정산](https://www.data.go.kr/data/15141809/openapi.do) |
| 표준코드 | 품목·품종·시장·등급·원산지·단위 대응 | [aT 코드](https://www.data.go.kr/data/15141818/openapi.do) |
| 관측 기상 | 산지별 온도·강수·일조 등과 생육/출하 조건의 시차 관계 | [기상청 ASOS](https://www.data.go.kr/data/15059093/openapi.do) |
| 역사적 기상예보 | 예측 시점에 이미 발표돼 있던 미래 기상 전망 | [기상자료개방포털](https://data.kma.go.kr/data/rmt/rmtList.do?code=420&pgmNo=572), API/파일 확보 범위 별도 확인 |
| 생산량·재배면적 | 작물·작형·지역별 공급 여건 및 산지 구성 | [KOSIS 엽채류](https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1ET0028), [근채류](https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1ET0029), [조미채소](https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1ET0291) |
| 수입량·수입액 | 품목별 수입 공급 변화·단가·국가별 구성 | [관세청 품목별](https://www.data.go.kr/data/15101609/openapi.do), [국가별](https://www.data.go.kr/data/15100475/openapi.do) |
| 달력 | 요일·월·계절·명절·시장별 확인된 휴장 | 공식 달력/시장 공지와 출처를 함께 기록 |

위 자료는 모두 핵심 후보로 유지하되 실제 기여는 검증으로 판단한다. **KREI 자료는 사용 불가로 제외**한다. 정산 거래량을 반입량·저장량·출하전망의 직접 대체값이라고 부르지 않는다. 마늘 생산량을 깐마늘 가공품 생산량이라고 부르지 않는다.

2026-09-28 조사에서 2014년 5품목 관련 거래 표본을 찾았으나, 당시 시장 구성이 최근보다 좁고 정가수의가 포함된다. 이는 2014년부터 전국 경매 가격이 일별로 모두 있다는 증거가 아니다. 시장×품목×날짜의 실제 조회와 데이터 품질 결과로 확보 범위를 기록한다. 상세 근거는 [조사 문서](data-feasibility.md)에 있다.

## 4. 자료 구조·출처·공개시점

API로 수집하고 소수의 테이블에 보관한다. 작업용 SQLite/DuckDB 단일 DB와 필요 시 테이블·연도별 Parquet 스냅샷을 사용하며 일자별 소파일을 늘리지 않는다. 현재 표본은 SQLite에 있다. 데이터 파일은 Git에 넣지 않고 스키마·수집·검증 코드와 실행 설명을 추적한다.

필수 정보는 출처 URL/기관, 비밀값을 제외한 요청 조건, 관측기간, 품목/시장/코드, 공개시각과 그 정밀도·근거, 버전 공개시각, 최초 확인·수집시각, 원문 수정필드, 응답 해시, API 상태, 페이지/작업 완전성이다. 인증키는 환경변수나 외부 `.env`에서 읽고 Git·로그·프로세스 인자·DB에 기록하지 않는다.

자료는 수집 당시 응답을 보존하고 수정된 응답을 덮어쓰지 않는다. 재시도·작업 재개는 같은 데이터를 무작정 중복 가산하지 않도록 하되 실제 서로 다른 거래나 버전을 지우지 않는다. 0건 정상 응답과 네트워크/인증/한도 오류를 구분한다. 코드 앞자리 0, 원문 소수, 부호, null을 유지한다.

**백테스트는 예측 시점에 실제 공개돼 있던 버전만 사용한다.** 관측일·낙찰시각·정산일·KOSIS 최종수정일·aT `mdfcn_dt`를 최초 공개일로 간주하지 않는다. 수입자료는 다음 달 15일 일괄 연결이 아니라 실제 발표 달력과 상세자료 공개시점을 사용한다. 당해 생산량도 실제 발표 전에는 사용할 수 없다. 공개일만 확인되면 하루가 끝난 후부터 사용하되 API 지연도 반영한다.

당시 버전이 없는 현재 수정자료는 엄격한 실시간 재현 검증과 구분해 후향적 검증으로 명시한다. 단순히 시차를 늘려도 과거 버전이 복원되지는 않는다. 가격 자체의 역사적 버전이 없으면 기본 모델에도 같은 제약이 적용된다. 기상예보는 예측 기준시각 이전에 발행된 것만 쓰고 미래 실제 관측값으로 대체하지 않는다.

## 5. 변수 가공과 탐색

가격·물량·기상·수입·생산 정보를 시간 범위와 연결 방식을 바꿔 검증한다. 직전 n일뿐 아니라 이동평균·지수가중평균·중앙값·변화율·누적량·분산/표준편차·최댓값/최솟값, 직전 N개월 통계, 계절·전년 동기 비교, 장단기 추세 차이 등을 후보로 둔다. 최근 가격동향도 같은 방식으로 분석한다.

날씨의 생육기 누적 영향, 생산·수입 발표 시차, 산지와 시장의 연결을 구분한다. 저빈도 자료를 일별로 반복해서 사용하더라도 독립 관측이 늘었다고 보지 않는다. 산지 가중치·결측 대체·스케일링·코드 매핑의 학습된 요소는 각 학습 구간 안에서 계산한다.

최적 n/N, 변수 조합, 학습기간, 재학습 방식은 반복 실험으로 찾는다. 초기 탐색 범위를 영구 상한으로 고정하지 않으며 확장/축소 이유와 시도 내역을 기록한다. 여러 가공변수의 상관관계로 중요도가 분산되거나 중복 계산될 수 있음을 점검한다.

## 6. 모델과 학습 방법

설명을 제공할 수 있는 사용 가능한 예측 방법을 폭넓게 비교한다. 아래는 출발 후보군이며 최종 승자를 미리 정한 목록이 아니다.

- 기준모델: 직전 유효가격 유지, 계절 순진 예측, 단순 이동평균 등. 휴장/무거래 처리와 공식 점수 대상은 모든 모델에 동일 적용.
- 통계모형: ETS, ARIMA/SARIMAX, 동적 회귀, 구조적 시계열 등.
- 표형 기계학습: 규제 회귀/GAM, 랜덤포레스트, XGBoost/LightGBM/CatBoost 등.
- 시계열 신경망: RNN/LSTM, TCN, N-BEATS/N-HiTS, TFT 등. 자료량·설명 가능성·재현성과 실제 성능을 확인한 뒤 사용.
- 결합: 통계+기계학습 잔차 보정, 학습 구간 밖 예측으로 학습한 앙상블/스태킹, 품목·예측거리별 구성.

일별 다단계 예측은 직접 예측·재귀 예측·다중출력 등을 비교하고 중기는 직접 학습과 일별 예측의 공식 방식 집계를 비교한다. 단일 공통 모델, 품목별 개별 모델, 공통+개별 보정을 비교한다. 특정 품목이 지속적으로 부적합하면 개별 모델을 허용한다. 최종 시스템은 품목·예측거리별 선택을 포함하더라도 버전과 선택 규칙이 고정된 하나의 운영 구성이다.

## 7. 가설·백테스트·채택 기준

주요 검증 가설은 (1) 가격 이력 가공이 단순 기준모델보다 유리한가, (2) 거래물량·구성·외부자료가 같은 평가기간에서 추가 이득을 주는가, (3) 품목/거리별 개별화가 공통 모델의 취약점을 개선하는가, (4) 설명 순위와 예측범위가 시점에 따라 안정적인가다. 가설별 변수 제거·추가 비교를 남긴다.

무작위 분할 대신 rolling/expanding origin으로 시간 순서를 지킨다. 가능한 긴 기간을 학습/검증에 활용하되 최종 평가 구간은 반복 튜닝에서 분리한다. 가격만의 장기 실험과 외부변수 추가 실험은 같은 평가 구간에서 비교한다. 10일·2순·3순의 정답 구간이 겹치는 학습표본, 공개되지 않은 학습 정답을 제거한다. n년 백테스트의 n은 실제 유효 데이터 길이에 맞춰 최대한 확보하며 단일 유리한 계절만 고르지 않는다.

| 판단 항목 | 채택 원칙 |
|---|---|
| 대회 성능 | 공식 평가 산식·품목/회차 비중을 최우선 적용 |
| 보조 지표 | MAPE·MAE·RMSE를 함께 기록. MAPE 개선과 MAE 악화가 동시에 발생하면 연구 성공으로 판정하지 않음 |
| 통계적 근거 | 같은 시점의 예측오차를 비교하는 Diebold–Mariano 검정 사용. 예측거리 중첩과 손실차 자기상관을 반영하고 반복 비교의 다중검정 문제 관리 |
| 품목·시기 | 평균만 보지 않고 5품목·단기/중기·예측거리·계절·추세 국면별 성능 확인 |
| 운영 선택 | Model Confidence Set으로 여러 후보를 운영 화면에 남기지 않음. 검증을 통과한 후보에서 공식 점수와 재현성·안정성·복잡도를 기준으로 하나의 운영 구성 선택 |
| 재현 | 데이터 버전·코드 커밋·환경·학습/평가기간·변수 설정·난수·예측시각 기록 |

DM 검정의 손실함수·유의수준·자기상관 처리·다중비교 보정은 실제 비교 실행 전에 기록해 결과를 보고 바꾸지 않는다. 통계적으로 차이가 불분명한 결과를 개선 입증으로 표현하지 않는다. 0 또는 비정상 정답의 MAPE 처리는 공식 규칙과 유효 관측 집합을 따르며 유리하게 제외하지 않는다.

2026-09-29 추가 합의: 앞으로 학습 결과는 **통계적 유의성 검토까지 완료한 뒤** 최종 보고한다. 평균 성능, 같은 날짜의 기준모델 비교, 시계열 의존성과 다중비교를 고려한 검정, 표본·예측 coverage 한계를 함께 제시한다. 검정을 할 수 없으면 이유를 명시해 판단 불가로 결론 내리고, 유의하지 않다는 것을 동등성 입증으로 해석하지 않는다. 실행 중 진행 보고와 최종 결과 보고를 구분한다.

이번 2017-01-01~2018-12-20 확장 평가의 검정 규칙은 p값 계산 전에 다음과 같이 고정한다. 이미 평균 성능을 확인했으므로 사후 탐색 검토이며 사전등록된 확증 검증이라고 부르지 않는다. 두 학습모델 각각을 직전가격 기준선과 비교하고, 5품목×2모델×4재학습 주기×10예측거리×2손실(AE·APE)의 **800개 검정 전체**에 Holm 보정을 적용한다. 양측 DM 검정·유의수준 5%, 실제 달력일 간격을 보존한 Bartlett HAC 9일을 주 분석으로 하고 28일을 민감도 분석으로 별도 보정한다. 누락된 날짜의 가격·오차를 채우거나 예측거리들을 독립 날짜처럼 합치지 않는다. 두 손실에서 모두 평균 차이가 음수이고 보정 p<0.05일 때 해당 조합의 개선 근거로 판단하며 민감도 결과도 함께 표시한다. 30쌍 미만은 이번 분석의 실무적 최소 표본 기준에 따라 추론을 보류한다(30 이상이면 점근 근사가 보장된다는 뜻은 아니다). 검정 불가 항목도 보정의 800개 분모에 남기며, 비유의·악화·추론 불가를 구별한다.

방법 근거: [Diebold–Mariano 원 논문](https://doi.org/10.1080/07350015.1995.10524599), [Holm 보정 공식 R 문서](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/p.adjust.html), [결측 시계열 HAC의 원 연구](https://www.federalreserve.gov/pubs/ifdp/2012/1060/ifdp1060.htm). HAC 공분산은 관측된 손실차를 중심화해 달력 간격으로 계산하며 관측 쌍 수로 평균의 표준오차를 정규화한다. 이는 실제 가격이나 오차의 결측을 0으로 대체한다는 뜻이 아니다. 현재 수정본 기반 후향 자료, 계절·구조 변화, 정보성 결측, 모델 추정 불확실성 및 제한된 시장 때문에 이번 p값만으로 미래 운영 성능을 보장하지 않는다.

특정 품목이 나쁘면 여러 시점에 걸친 문제인지, 특정 시점에 집중되면 계절성·추세/구조 변화·시장 구성 변화·자료 누락 때문인지 분석한다. 원인 후보별 데이터 보완·학습기간 조정·개별 모델·국면 대응을 검증하며 부진 구간을 숨기지 않는다.

## 8. 설명과 대시보드

품목 선택 시 적어도 최근 1년의 실제가격(실선)과 당시 생성한 예측가격(점선)을 보여준다. 조회기간 N일과 일/주/월/분기 구분을 제공한다. 과거 점선에 전체 자료로 사후 학습한 예측을 끼워 넣지 않는다. 표시 집계 때도 단위·가격 정의·예측거리·예측 기준시각을 유지한다.

예상 가격 범위는 사용자 옵션으로 켜고 끌 수 있게 한다. 통계 용어보다 예상 가격·범위·상승/하락 방향·기준일을 먼저 보여주고, 예측 범위의 의미와 포함률/폭 검증 결과를 쉽게 설명한다. 범위는 수익 보장이나 확정 가격이 아니다.

가격 변화의 배경 후보를 우선순위로 보여준다. 전체 검증기간 중요도, 개별 예측 기여, 변수 제거 실험, 시점별 안정성과 자료 품질을 종합한다. SHAP·permutation importance·회귀 계수/부분효과 등 모델에 맞는 방법을 비교한다. Attention 가중치나 변수 중요도만으로 인과를 주장하지 않는다. '폭염이 가격 상승의 원인'으로 단정하지 않고 '최근 기온 변화가 이번 예측의 상승 방향에 기여'처럼 모델과 관측 사실을 구분한다.

휴장 연결값·자료 지연·무거래·모델 신뢰도 저하를 알아보기 쉽게 표시한다. 통계에 익숙하지 않은 사용자에게 불필요한 학습 구현 세부사항을 강요하지 않는다.

### 2026-09-28 추가 수집·단계별 실험

사용자가 추가 자료 확보와 다음 네 단계의 실제 비교를 승인했다. (1) 기존 모델을 고정하고 상대 변화·동일 요일·실제 관측 거래일 변수 비교, (2) 시장별 가격·거래구성 추가, (3) 개발구간에서 효과가 확인된 변수로 목표값 표현·예측거리별 학습 비교, (4) 발표 당시 값과 시각이 확인되는 외부자료 결합. 기존 대시보드 결과는 보존하며, 실험 결과가 개선을 입증하기 전 운영모델로 교체하지 않는다.

첫 추가 배치는 가락·강서 2016-01-01~03-31의 5품목군을 대상으로 한다. API 한도와 디스크를 고려한 배치이며 장기 수집 목표의 상한이 아니다. 2014년부터 학습하고 이미 결과를 확인한 2015년은 개발·선택 구간으로 사용한다. 신규 2016년 1분기는 독립된 탐색적 평가 구간으로 남긴다. 수집 상태·자료량은 먼저 점검할 수 있지만 평가 오차를 보고 변수·모델을 선택하지 않는다. 한 분기 결과만으로 연중·다년 성능을 입증하지 않는다. 추가 연도는 계속 미사용 평가 후보로 보존한다.

비교 타깃은 기존 두 시장의 경매·kg 거래, signed 총금액/순중량 정의를 고정한다. 시장 확장 시 별도 계열로 관리한다. 학습 자료는 매 시점 정답이 알려진 관측까지만 확장하며 시장/거래구성 통계·결측 처리·목표값 변환도 미래를 참조하지 않는다. 희소한 품목의 관측을 임의 채워 표본을 늘리지 않는다.

후보 추가는 개발구간의 동일 예측일·예측거리에서 MAPE와 MAE를 함께 개선하는지를 기준으로 한다. 원자료 가격 지속성 기준선도 유지한다. 단계별 고정 구성과 후보 탐색 내역을 저장하고 최종 구간에서는 다시 선택하지 않는다. DM은 절대오차/절대백분율오차의 시점별 차이에 대해 자기상관과 중첩 예측을 고려하고, 5% 유의수준 및 Holm 다중비교 보정을 적용한다. 날짜가 불규칙한 관측을 단순한 연속 거래일로 간주하지 않는다. 일·주·월·계절 집계와 예측거리별 표본 수·누락률을 함께 보고한다.

외부자료 실험은 문서로 검증된 발표값만 해당 발표 이후 연결한다. 발표 근거가 없는 현재 API 수정값은 엄격한 당시 정보 실험에서 제외하고 제외 이유를 남긴다. 가격 원자료 자체는 수정본 기반 후향적 평가라는 기존 한계를 유지한다.

### 2026-09-29 품목별 성능 차이 진단 규칙

기존 평가 결과를 본 뒤 제기한 가설의 탐색적 진단이며, 아래 규칙은 진단 실행 전에 고정한다. 예측모델을 재학습하거나 운영 구성을 변경하지 않는다. 가격 정의와 2017-01-01~2018-12-20 평가기간을 유지하고, 2014~2016년은 계절별 기술통계의 비교 구간으로만 사용한다. 기존 가격 export와 DB 재구성 가격·거래량·날짜가 일치해야 진행한다.

- 배추·무: 양쪽 실제가격이 있는 연속 달력일만으로 `100×|log(P_t/P_{t-1})|`를 계산한다. 대관령(100)·서울(108)·해남(261)의 직전 7일(t-7~t-1) 평균기온, 평균 일교차, 합계강수를 각각 설명변수로 하고 월·연도·요일 고정효과를 포함한다. 기상 18개와 동시 경매 순중량의 절대 로그변화 2개를 고정된 20개 검정으로 관리한다. 달력 간격을 보존한 Bartlett HAC 9일을 주 분석, 28일을 민감도 분석으로 하고 각각 양측 5%·Holm 20개 보정을 적용한다. 불가 항목도 보정 분모에 유지한다. 완전 rank, 잔차 자유도 양수, 표본 `n≥max(60,5×설계열 수)`를 이번 실무 기준으로 사용한다. 강수 공백은 0으로 바꾸지 않고 7일 완전관측 창만 사용한다.
- 건고추: 실제 관측 사이의 간격(1일/2~7일/8일 이상), 행수·순중량 및 시장·소분류·등급·산지 비중의 총변동거리(TVD)를 기술한다. 시장 합계와 전체 순중량·금액이 일치하고 비중이 유효한 날짜만 구성거리를 계산한다. 음수 정정 원자료는 보존하되 음수 비중은 TVD에서 제외하고, 미상 범주는 명시하며 조용히 재정규화하지 않는다. 이번에는 표본수와 무관하게 기술진단만 수행하며, 연속일 쌍 60개 미만이면 표본 부족도 명시한다. 별도 구성 회귀는 이번 20개 검정에 포함하지 않는다. 세부 셀 가격이 없으므로 구성 변화의 가격 기여율을 주장하지 않는다.
- 양파: 기존 예측의 동일 표본에서 `δ=모델예측−직전가격`, `e=실제가−직전가격`으로 두고 `ΔMSE=평균(δ²)−2×평균(δe)`를 확인한다. 반대방향 수정은 `δe<0`, 같은 방향의 해로운 과잉 수정은 `δe>0`이고 `|δ|>2|e|`인 경우로 구분한다. 주표는 매일 재학습·1일 후 예측 두 모델이며, 다른 조합을 제시할 경우 전체 조합을 함께 기록한다. MAE·MAPE 유의성은 동일 입력 해시의 기존 DM 결과를 연결한다.

- 대관령100·서울108·해남261 ASOS의 목표일 직전 7일 평균기온과 강수 자료 완전성을 기록한다. 빈 강수량은 0으로 바꾸지 않는다. 이 지점들이 실제 출하 산지를 대표한다고 가정하지 않고, 사후 수정본과 과거 발표시각 미확인 한계를 명시한다. 공식 기상·시장 자료의 사건 시점과 일치 여부는 배경 근거로만 사용한다. KREI는 사용하지 않는다.
- 연속 달력일 관측쌍에서 `100×|log(P_t/P_{t-1})|`와 동시 중량변동 크기·시장 비중 TVD·등급 비중 TVD·세 지점 직전7일 평균기온 각각의 연관성을 월·연도·요일 통제 후 검토한다. 2품목×6변수=12개 고정 검정, 달력 Bartlett HAC9일 주 분석/HAC28일 민감도, 양측 5% 및 각 family Holm12 보정이다. 기존 rank·표본 기준을 재사용하고 불가 검정은 p=1로 보정 분모에 남긴다. 동시 물량과 구성은 예측 시점에 알 수 있는 선행변수가 아니며, 가격과 공유하는 산술 구조도 있어 통계적 연관성을 원인 또는 예측력으로 해석하지 않는다.
- Luna 구현/Astra 검토 후 실행한다. 모든 사건·분해 잔차·12개 검정·요청 출처·해시와 Markdown 해석을 `outputs/diagnostics/spikes-20260930/`에 보관한다. 결과를 확인 사실, 통계적 연관성, 미확인 원인 후보로 구분한다. 예측모델·cron·대시보드는 이 원인 진단만으로 교체하지 않는다.
