# 2순·3순 MAPE 10% 목표 실험 결과

- 실험: `PERIOD_DIRECT_MAPE_ROLLING_V3`
- 실행: 2026-10-15~16 KST
- 판정: **`completed_price_gain_below_goal` — F 대비 관측 가격지표 개선, 10% 목표 미달**

## 결과와 판단

개발자료로 선택한 정책 P는 **MAPE8 14.4608% → 14.3279%(−0.1329%p), MAE8 232.3104 → 225.4959원/kg(−6.8145원/kg)**으로 기존 F보다 낮았습니다. 상대 감소율은 각각 약 0.92%, 2.93%이며 예측·채점 범위 손실은 없습니다. 양파 2순을 제외한 7개 셀에서 두 지표가 모두 낮았습니다.

그러나 **MAPE8≤10%와 개별 8셀 모두≤10%는 모두 미달**입니다. 10% 이내인 셀은 깐마늘 2순·3순의 2개이며, 이는 기존 F에서도 달성하던 셀입니다. P의 평균은 목표보다 4.3279%p 높습니다. 10%에 도달하려면 현재 MAPE를 추가로 약 30.21% 줄여야 합니다.

사전 지정한 DM/HAC·Holm 검정에서는 주비교 32개와 기전 비교 64개 모두 유의한 개선·악화가 없었습니다. P−F의 공동 목표순 블록 재표집 95% 구간도 두 블록 길이·두 지표에서 모두 0을 포함합니다. **관측 개선은 확인했지만 통계적 우월성은 불확정**입니다. 비유의를 동등성으로 해석하지 않습니다.

단순 기준 B0와 비교하면 P의 MAPE8은 1.4044%p 낮지만 MAE8은 **4.2631원/kg 높습니다.** 따라서 “모든 기준보다 우수하다”거나 “MAPE 10% 목표를 달성했다”고 결론내리지 않습니다. P는 이번 개발 규칙으로 선택된 연구 후보이며, 공식 대회·운영 모형으로 채택하지 않았습니다.

## 비교 설계와 사전 선택

[실행 전 고정 계획](period_mape10_protocol.md)에 따라 기존 가격·물량·순 이력·가용성·달력 특징만 사용했습니다. 시장구성 C1·날씨·신규 수집을 추가하지 않았습니다. 가락·강서의 실제 양수 일별 경매가격을 1~10일, 11~20일, 21일~월말별로 평균한 대리목표이며, 관측일 3일 미만의 정답은 만들지 않고 빈 날짜를 채우지 않습니다.

발행은 완료순 종료+2일 10시라는 가정이며 입력 종료일은 발행일−2일입니다. p_ref는 이 종료일 이하의 가장 최근 실제 일별 관측가격입니다. 학습에는 목표순 종료+2일≤적합일인 정답만 들어갑니다. 훈련 M/MW는 가격비 정답의 역수를 정확히 한 번 곱한 절대손실과 계수 L1 규제를 사용했습니다. 훈련 선형 출력≥0.05, 평가 출력 하한 0.05를 고정했고 실제 시험에서 하한에 잘린 출력은 **0건**입니다.

| 구성 | 의미 | 고정 설정 |
|---|---|---|
| B0 | 기존 개발에서 고른 단순 기준 | 무 3순은 최근 일가격, 나머지는 최근 완료순 평균 |
| F | 저장된 기존 B1 시험 예측 | 로그가격비 Ridge, 시험에서는 분기별 적합 |
| R | F와 같은 표현·입력, 순마다 확장 재학습 | 기존 셀별 alpha=1 계승 |
| W | R에 최근성 가중 | 반감기 72순, 평균 1인 가중치 |
| S | 같은 특징의 가격비 제곱손실 Ridge | alpha=100 |
| M | 가격비의 직접 MAPE 목적 LP | lambda=0.01 |
| MW | M에 최근성 가중 | lambda=0.01, 반감기 72순 |
| P | 개발자료로 품목별 선택한 주정책 | 배추 R·무 R·양파 R·깐마늘 W |
| P_global | 개발자료로 고른 전 품목 공통 구성 | R, 진단용 |

S/M/MW 규제는 2020~2021년 각 분기 첫 합법 발행 원점에서 선택했습니다. 선택에 쓴 마지막 정답은 2021-11-02에 가정상 확정됩니다. 이후 2022~2023년 전체 개발구간에서 품목별 두 거리·두 연도의 MAPE와 각 연도 MAE≤F의 105% 조건으로 P를 선택했습니다. 선택된 네 품목 모두 MAE 보호조건을 통과했으며 위험 후보는 없습니다. 선택 파일을 시험 전에 동결했고 시험 결과로 방법을 교체하지 않았습니다.

기존 F의 개발은 순별 재학습이었고 예측행은 저장되지 않았습니다. 동일 alpha·표본·경계인 R 개발 예측을 재사용해 F 개발 참조를 복원했습니다. 이는 별도의 독립 모형이 아닙니다. R/W의 alpha는 이미 2022~2023 결과를 이용해 선택된 값이라는 후향 선택 한계도 유지합니다. 시험 F/B0는 기존 저장값을 그대로 재사용했습니다.

## 통계평가

주검정은 P−F·P−B0 × 8셀 × AE/APE = **32개를 한 가족**, 기전은 W−R·S−R·M−S·MW−M × 8셀 × AE/APE = **64개를 별도 가족**으로 고정했습니다. 달력순 인덱스의 Bartlett HAC lag3을 주분석, lag6을 민감도 분석으로 사용했고 각 가족·대역폭별 Holm 5% 보정을 적용했습니다. 각 가설의 같은 쌍은 97~98개 고유 목표순입니다.

두 대역폭에서 32개와 64개 모두 검정을 완료했고, **Holm 유의 개선·악화는 0개**였습니다. 주가족의 최소 조정 p값은 lag3 0.8061, lag6 0.9482입니다. 모든 셀의 원시 p·조정 p·손실 차이·분산·지원 수는 `score_report.json`에 보존했습니다.

공동 목표순 순서와 결측 위치를 유지한 원형 블록 재표집은 길이 6순·12순, seed0, 각 2,000회입니다. 모든 셀에 같은 목표순 인덱스를 적용하고 매 복제의 셀별 오차를 동일가중했습니다. 아래는 **실제 점 추정치**와 재표집 95% 백분위 구간이며, 재표집 평균을 실제 개선폭으로 대체하지 않았습니다.

|---|---:|---:|---:|
