2.1 목표·원점·가용성 계약
- 순 구간은 월 1~10일, 11~20일, 21일~월말. 발행시점은 완료순 종료+2일 10시(KST)라는 기존 대리시험 가정을 유지한다. 목표 2순·3순 매핑과 발행일−2일 입력 종료 정책도 V3와 같게 재생한다.
- 과거 각 원점 u의 p_ref(u)>0는 u 시점에 알고 있던 마지막 적격 일별 가격이다. 과거의 목표순 가격 Y(u,k)>0는 현재 예측 원점 o에서 이미 기간이 끝나고 가정상 공개된 경우에만 사용한다. 과거 사례의 상대가격비 r(u,k)=Y(u,k)/p_ref(u)를 저장한다.
- 후보를 만들 때도 과거 원점 u의 특징은 u 이전의 정보만 이용한다. 현재 원점 o의 목표순 정답이나 이후 거래중량으로 후보·스케일·가격비를 결정하지 않는다.
- 품목·거리 k를 섞지 않는다. 과거 후보의 목표순은 현재 목표순과 36순 순환 달력거리 ±3순 이내여야 한다. 연말/연초는 순환거리로 계산한다.
- 동일한 과거 목표순을 여러 원점이 예측했다면 과거 목표순당 가장 가까운 합법 원점 1건만 남긴다(동률은 빠른 원점). 후보 8개 미만은 insufficient_analogs로 기록한다.
2.2 Q0/Q1 공통 출력
- 적격 후보에서 정확히 8개 서로 다른 과거 목표순을 선택한다.
- 선택된 양수 상대가격비 r_j에 대해 r_hat=weighted_median(r_j, weight_j=1/r_j)를 계산하고, prediction=p_ref(o)×r_hat을 출력한다. 경험적 APE 목적에 맞춘 고정 집계식이며 실제 조건부 최적 예측을 보장하지 않는다.
- 결정적 동률 처리는 비율 오름차순 정렬 후 누적가중 50%에 처음 도달하는 사례의 비율을 선택한다. 원시 float64로 계산한다. 학습·평가 정답을 조정하지 않는다.
- Q0는 목표순의 계절거리가 가까운 순서로 8개를 선택한다. 동률은 과거 원점의 최신순, 다시 고정 키 사전순으로 결정한다.

   - 표준화된 네 특징의 동일가중 유클리드 거리가 작은 순서로 8개를 선택한다. 동률은 계절거리, 최신 과거 원점, 고정 키 순으로 정한다. 특징 가중치·K·계절창을 2024~2026 결과로 변경하지 않는다.
