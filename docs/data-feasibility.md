# 농산물 가격예측 데이터 확보 가능성 조사

이 문서는 본수집 코드 개발 이전의 조사 기록이다. 이후 확정된 저장 구조와 실제 실행 상태는 [수집·검증 실행 기록](COLLECTION.md)을 기준으로 확인한다. 아래의 미구현·미검증 표기는 조사 당시 상태를 보존한 것이다.

조사일: 2026-09-28 KST. 모델 개발·학습·예측성능 검증은 하지 않았다. 공식 문서·화면 확인과 인증된 API 소량 조회를 수행했다. 요청조건, 응답, 출처, 수집일, 응답 해시는 [조사 증거](data-feasibility-evidence.json)에 보관했다. 초기 조회 일부는 수집일만 기록했고 이후 조회는 UTC 시각도 기록했다. 인증키와 키가 포함된 URL은 저장하지 않았다.

**판정: 조건부 진행 가능. 사용자 신청 후 경매원천 API 접근에 성공했고, 2014년에도 5품목 관련 거래가 존재함을 확인했다. 다만 최근과 시장 구성이 다르고 정가수의도 포함하므로 12년 이상 전국 경매 가격이 확보됐다고 해석하면 안 된다.** 정산 집계와 원천 거래의 대조 결과 및 새로 확인한 품질 문제는 9절에 정리했다. 가격의 최장 연속기간·공식 타깃 집계식·과거 공개본은 아직 확정되지 않았다. 자료 확보 가능성과 예측성능 향상은 별개이며, 후자는 아직 검증 전이다.

## 2. 다섯 품목의 가격 표본에서 발견한 차이

다음 건수는 API의 해당 조건 `totalCount`이며, 전국 일별 거래량이나 전체기간의 완전성을 뜻하지 않는다.

| 품목 | 실제 확인한 표본 | 필요한 처리 |
|---|---|---|
| 배추 | 가락 2018-06-15 58행, 2026-09-23 55행. 최근 첫 행에 수입 배추 존재 | `10/01` 코드 확인. 국내 시장 거래와 국내산 농산물을 구분. 수입산 포함 여부는 대회 타깃 정의와 대조 |
| 무 | 가락 동일 날짜 각각 30행·17행 | `11/01`. 봄무·고랭지무 등 작형·품종 구성 변화 관리 |
| 양파 | 가락 동일 날짜 각각 133행·88행 | `12/01`. 포장 중량·품종·시장 구성 통일 후 집계 |

| 건고추 | 가락 2018-06-15·2026-09-23 0행. 광주각화 2018-09-17 9행, 2026-09-23 1행. 대전오정 2026-09-23 1행 | `12/07`. 특정 시장·날짜 0건은 전국 부재가 아님. 계절·시장별 거래 빈도 확인 필수 |

**정산정보 전체를 곧바로 경매 방식의 경락가로 간주하면 안 된다.** 실제 응답에는 `trd_se`(매매구분)가 있다. 특히 깐마늘은 확인한 표본의 거래방식 때문에 엄격한 ‘경매만’ 조건에서 가격 시계열을 만들 수 있는지 추가 확인해야 한다. 임의로 정가수의 거래까지 포함하여 타깃을 변경하지 않는다. 대회가 사용하는 경락가의 실제 포함범위를 확인해야 한다.

가격 필드의 단위도 바로 원/kg이라고 간주할 수 없다. 예를 들어 깐마늘 20kg 행에는 단위물량·단위총물량·총가격·평균가가 따로 있다. `평균가/포장중량`과 `총가격/총중량`은 표본에서도 일치하지 않았다. 공식 집계식과 단위 의미를 확인하고 농넷 표시값과 대조한 후 전국 가격을 확정한다. 행별 평균가를 단순 평균하지 않는다.

표준코드 API [농축수산물 표준코드](https://www.data.go.kr/data/15141818/openapi.do)는 최초 인증 오류 후, 사용자의 신청 완료 통보에 따라 재조회하여 시장코드 응답에 성공했다. 관세청 두 API도 같은 기존 키로 정상 응답했다. 과거 코드의 유효기간·개정 대응표까지 확보된 것은 아니다.

정산 거래량은 실제 정산된 거래의 물량이다. 시장에 들어온 총 반입량과 같은 의미인지 별도 검증해야 하며, 확인 전에는 ‘정산 거래량’으로 표기한다.

## 3. 미래정보를 차단한 백테스트의 제약

1. **관측일과 공개일은 다르다.** 기상은 조회 가능한 전일까지, 월별 수입은 실제 공개 후, 생산량은 실제 발표 후에만 변수로 사용한다. 관세청 안내는 매월 15일경 정정·취하를 반영한 현행화를 명시한다. 월말에 해당 월의 확정 수입량을 알았다고 가정하면 안 된다.
2. **현재 API가 주는 과거 값은 당시 최초 공개값과 다를 수 있다.** 실제 2016년 KOSIS 응답의 최종수정일은 엽채류 2018-09-07, 근채류 2018-09-05였으며, 마늘 면적에는 2022-01-10이 표시됐다. 최종수정일은 최초 공표일이나 수정 전 수치가 아니다. 날짜만 늦춰 쓰는 것으로 빈티지가 복원되지는 않는다.
3. 발표본·개정본을 확보할 수 있으면 당시 공개 버전을 사용한다. 불가능하면 해당 변수를 제외한 엄격 검증과 최신 수정자료를 사용한 후향적 검증을 구분하고 한계를 명시한다. 앞으로 수집하는 자료는 최초 관측본과 이후 수정본을 보존할 수 있다.
4. 과거 예측일 이후의 실제 날씨는 입력할 수 없다. 역사적 발표 예보를 확보하지 못한 구간은 예측시점까지의 관측 날씨만 사용한다. 단기예보 자료가 있다고 해서 2순·3순 이후 날씨까지 같은 해상도로 알 수 있었던 것은 아니다.
5. 휴장, 특정 품목 무거래, API 누락을 각각 표시한다. 확인된 휴장의 표시가격에는 이전 장 마감값을 이어 쓸 수 있으나 모든 결측을 휴장으로 처리하지 않는다. 거래량은 가격처럼 전일 값을 복사하지 않는다. 특히 건고추의 무거래를 일반 휴장으로 오인하면 가격이 인위적으로 안정되어 평가가 왜곡될 수 있다.

빈티지 관리의 방법론 참고: [Philadelphia Fed 실시간 자료 연구](https://www.philadelphiafed.org/surveys-and-data/real-time-data-research/real-time-data-set-for-macroeconomists). 비거래 시점의 통계적 효과 참고: [Lo·MacKinlay, 비동시거래 연구](https://www.nber.org/papers/w2960). 이 연구를 모든 결측일의 전일값 보간을 정당화하는 근거로 사용하지 않는다.

## 4. 현재 기획에 대한 판단과 다음 검증

- 가격·거래량의 시차, 이동평균, 변동성, 계절·추세 변수 및 관측 기상 변수의 실험은 데이터 경로상 가능하다. 생산·수입 변수도 후보로 유지하되 공표 지연과 수정 이력을 먼저 해결한다. 낮은 빈도의 통계를 일별로 늘려도 독립적인 정보가 늘어나는 것은 아니다.
- **기간 기준은 신뢰성을 유지하면서 확보 가능한 최장기간이다. 10년은 필수조건이 아니다.** 품목별 시작일을 다르게 허용하고, 외부변수의 짧은 기간 때문에 긴 가격자료를 버리지 않는다. 가격 중심 장기 실험과 외부변수 추가 실험은 동일한 평가기간에서 비교한다. 최대 확보기간과 최적 학습기간을 구분하며 학습기간은 백테스트로 결정한다. 현재 직접 확인한 가격의 가장 이른 표본은 2018-01-15이며 이를 API의 최초 제공일로 해석하지 않는다.
- 장기 보완 후보로 [농정원 구 상세 경락가격 자료](https://www.data.go.kr/data/15083035/fileData.do?recommendDataYn=Y)도 확인했지만, 연결된 농식품 포털의 실제 과거파일·API 확보는 확인되지 않았다. 등록일 2015년은 관측자료가 그때부터 제공된다는 증거가 아니다. 다른 시장 자료를 전국 가격과 그대로 이어 붙이지 않는다.
- 대시보드의 실선·점선, 표시주기 변경, 설명 우선순위, 선택형 예측범위는 구현상 가능하다. 과거 점선에는 당시 학습자료만 사용한 백테스트 예측을 저장해야 한다. 자료 존재만으로 설명의 타당성·예측정확도·구간 포함률이 입증되지는 않는다.
- 본수집의 파일 관리 후보는 소수의 테이블을 보관하는 DuckDB와 검증용 Parquet 스냅샷이다. 예: 원응답/수집기록, 표준코드와 유효기간, 정산 거래, 날씨, 생산통계, 수입통계, 공표·수정 버전, 나중에 생성할 백테스트 예측. 이번 검증 표본은 추가 설치 없이 조회 가능한 단일 SQLite 파일로 보관했다(9절). 자동 수집 파이프라인은 구현하지 않았다.
- [공모전 안내](https://hackathon.imaginationgroup.co.kr/nongnet)의 오프라인 재현 조건에 맞춰 검증에 사용한 외부자료를 동결 보관해야 한다. 본선 공통자료·실행 템플릿 공개 전에는 자체 집계가격과 공식 타깃의 일치 여부를 확정할 수 없다.

다음 데이터 검증 우선순위:

1. 접근이 확인된 표준코드·관세청 API에서 과거 코드 대응표와 품목별 최장 제공기간·연속성을 확인. KREI 자료는 사용하지 않음.
2. 5품목 × 시장 × 기간의 제공범위와 거래방식 분포 확인. 특히 깐마늘의 경매자료 구성 가능성과 건고추의 유효 거래일.
3. 가격 단위·집계식·포함 품종·등급·원산지·매매구분을 공식 타깃과 맞추고 농넷 표시가격과 대조.
4. 출처·공표일·수정본을 갖춘 데이터만으로 첫 백테스트 가능한 교집합 기간 결정. 그 뒤에 변수·모델 실험과 DM 검정으로 넘어감.

사용자는 KREI 사용 불가 및 나머지 데이터셋 신청 완료를 통보했다. 이후 기존 키로 표준코드·관세청 두 API의 정상 응답을 확인했다. 에이전트는 신청서를 대신 제출하지 않았으며, 유료 데이터 구매·모델 학습·공모전 제출도 수행하지 않았다.

## 5. 추가 실조회: 기간과 거래 구성

### 전국 정산자료

표준코드 API가 반환한 33개 시장코드에 대해 2018-01-15와 2026-09-23의 5품목군을 조회했다. 부산국제수산 등도 포함한 코드 목록이며, 33개 모두 해당 농산물을 거래한다는 뜻은 아니다. 각 조건 최대 1,000행을 요청했고 아래 품목 표본에는 페이지 잘림이 없었다. 행 수는 정산 집계행 수이며 낙찰 건수·물량 비중과 다르다. 배추·무·양파·건고추는 중분류 전체, 깐마늘은 아래 소분류 후보만 추렸다.

| 품목 | 2018-01-15 관련 자료가 있는 시장 / 경매행이 있는 시장 | 2026-09-23 관련 자료가 있는 시장 / 경매행이 있는 시장 | 두 날짜의 전체 집계행 중 경매행 |
|---|---:|---:|---|
| 배추 | 31 / 22 | 31 / 30 | 170/444, 385/745 |
| 무 | 31 / 22 | 31 / 31 | 83/250, 245/336 |
| 양파 | 31 / 13 | 30 / 24 | 192/429, 155/296 |
| 깐마늘 후보 | 24 / 4 | 24 / 5 | 6/177, 23/197 |
| 건고추 | 5 / 3 | 9 / 7 | 3/6, 11/14 |

깐마늘 경매행은 2018년 표본에서 광주서부·익산·구미·창원팔용, 2026년 표본에서 서울강서·대구북부·광주서부·대전오정·익산에 있었다. 따라서 가락만 보고 깐마늘 경매자료가 없다고 결론 내릴 수 없다. 반대로 두 날짜에 거래가 있다고 일별 연속 가격이 확보된 것도 아니다.

33개 시장 전체의 2016-09-26·2017-06-15 정산 API 조회는 정상 응답 0건이었다. **이 정산 API에서 확인한 가장 이른 양성 표본은 2018-01-15**이며, 2018년이 최초 제공연도라는 보장은 없다. 이후 승인된 원천 API는 더 오래된 자료를 반환했다(9절). 가장 긴 연속기간은 시장×품목별 일별 수집과 누락 원인 분류 후 확정한다.

### 생산통계와 수입통계

1970~2026년 범위로 KOSIS 전국 면적·생산량을 실제 요청한 결과, 배추·무 합계 항목은 1980~2024년 각 45개년, 건고추는 1980~2025년 각 46개년, 양파·마늘은 1980~2026년 각 47개년의 숫자 응답을 확인했다. 이는 현재 수정본의 수록범위이지 각 연도 당시 이용 가능했던 버전의 확보 범위가 아니다. 배추·무 2025년 가을작형 발표본이 존재해도 연간 합계의 빈 값을 그 수치로 대체하지 않는다.

관세청 품목별 API는 2018~2025년 각각 1년, 2026년 1~8월을 조회했다. 아래 세부코드 후보에 해당하는 행은 5품목 각각 104개월 모두 존재했다. 0kg인 명시적 응답과 응답행 부재를 구분했다. 아직 2022년 양파 코드 중첩을 해결한 완성 시계열은 아니다.

## 6. 실험에 사용할 거래자료 구성 기준

아래는 확정된 수집·보존 원칙이며, 공식 대회 타깃이 공개되기 전에는 자체 집계값에 `provisional` 표시를 둔다.

1. **원자료와 타깃을 분리한다.** 정산자료는 정산일, 시장, 법인, 매매구분, 대·중·소분류, 원산지, 등급, 크기, 포장, 단위별 행을 원형 보존한다. 원천자료를 확보하면 원표번호·경매순서·경매순서2·법인상품코드·낙찰시각도 보존한다. 이 필드 조합의 유일성은 실제 자료에서 검사하고, 같은 가격·수량이라는 이유만으로 서로 다른 낙찰을 중복 삭제하지 않는다.
2. **품목 범위를 명시한다.** 기본 조회 중분류는 배추 `10/01`, 무 `11/01`, 양파 `12/01`, 마늘 `12/09`, 건고추 `12/07`. 배추 중분류에는 우거지·뿌리·절임배추 등도 있어 신선 통배추 타깃에 자동 포함하지 않는다. 깐마늘 후보는 `06/16/41/42/43`; 과거 `06`은 명칭 null, 최근 `41/42/43`은 한지/대서/남도다. 최신 코드 목록만으로 역사적 유효기간을 확정하지 않는다. 코드 API 전체 15,436개 중 첫 10,000개를 조회한 상태이며 전체 코드 수집 완료라고 표기하지 않는다.
3. **국내 시장과 국내산을 구분한다.** 원산지와 매매구분은 별도 차원으로 저장한다. 국내산/수입산, 경매/정가수의/전자거래의 포함범위는 공식 타깃 정의에 맞춘다. 지금은 경매만의 집계와 정산 전체 집계를 분리해 비교할 수 있도록 하되, 점수가 잘 나온다는 이유로 정답 정의를 바꾸지 않는다.
4. **금액·중량으로 집계하되 단위 의미를 먼저 검증한다.** 목표 단위 후보는 원/kg. `평균가`의 단순 평균을 사용하지 않는다. 개별 거래의 총금액·총중량이 검증되면 후보 집계식은 `선택 거래의 총금액 합 / 총중량(kg) 합`. 원천의 `scsbd_prc`·`qty`·`unit_qty`·`unit_tot_qty`·`totprc` 관계를 대조해 적용한다. 단위코드에는 g, kg, ton뿐 아니라 `.`, ml, L도 있다. 중량 변환 가능한 행만 가격 집계에 넣고 나머지는 격리·누락률 보고한다. 공식 타깃이 다른 산식이면 그 산식을 따른다.
5. **날짜를 보존한다.** API 필터인 `trd_clcln_ymd`는 거래정산일자다. 원천의 `scsbd_dt` 낙찰일시와 동일하다고 가정하지 않는다. 자정 전후 거래를 임의로 하루 이동시키지 않고 공식 타깃의 영업일 기준에 맞춘다. 낙찰시각은 공개시각이 아니다.
6. **결측 상태를 분리한다.** 정상 거래·확인된 휴장·품목 무거래·수집 실패·정산 미완료를 구분한다. 확인된 휴장에만 이전 마감 가격을 이어 표시하고 보간 표시와 마지막 실제 거래일을 남긴다. 거래량은 이어 채우지 않는다. 휴장일을 점수에 포함할지는 대회 규칙에 맞추고, 실제 거래일 성능도 별도 점검한다.
7. **구성 변화도 설명 후보로 남긴다.** 시장·등급·산지·수입산·매매구분별 물량 비중과 집계 제외율을 기록한다. 가격 변화가 동일 품질의 가격 변화인지 거래 구성 변화인지 구별하며, 설명 화면에서 이를 원인으로 단정하지 않는다.

| ASOS 일관측 | 명세상 D-1까지 제공, 정확한 일별 갱신시각 미확인 | 관측일 종료 이전 사용 금지. 앞으로 최초 확보시각을 기록. 과거 시각 불명 구간은 추가 지연 가정과 수정본 한계를 표시 |
| 생산량·면적 | 작물·작형·통계 종류별 발표일 상이 | 발표본 버전과 실제 보도시점으로 연결. 재배면적 선행 발표와 수확 후 생산량을 각각 관리 |
| 월 수입 | 월간 확정 발표일이 월마다 다르고 사후 수정 가능 | 실제 발표 달력 및 상세자료 확보시점 사용. 매월 1일·15일 일괄 연결 금지 |
| 기상예보 | 예보 발표시각과 예보 대상시각이 별도 | 예측 기준시각 이전에 발표된 예보만 사용. 과거 예보를 확보하지 못하면 미래 실제 관측값으로 대체 금지 |

공통 컬럼은 `source_url`, `series_id`, `reference_start/end`, `event_at`, `published_at`, `published_precision`, `version_published_at`, `first_seen_at`, `retrieved_at`, `revision_at`, `vintage_status`, `availability_basis`, `query_parameters`, `response_hash`로 정한다. 모든 시각은 시간대와 함께 저장한다. API 카탈로그의 수정일은 해당 관측값의 수정일이 아니다.

백테스트에서는 예측 기준시각 전에 **그 버전이** 공개된 자료만 선택한다. 공개일만 확인되면 보수적으로 다음 날 00:00 이후 사용하되 API 지연이 별도로 확인되면 더 늦은 시점을 적용한다. 최초 수집이 2026년이라는 이유로 검증된 2018년 발표본을 2026년에만 사용할 필요는 없지만, 반대로 2026년에 조회한 최신값을 2018년 발표본으로 소급해서도 안 된다. 공개시각을 증명할 수 없는 값은 엄격한 당시 정보 검증에서 제외하거나 후향적 실험으로 명시한다. **가격 자체도 현재 수정본만 확보된다면 기본 모델 역시 엄밀한 실시간 재현 검증이 아니다.**

학습에 넣는 정답도 재학습 시각까지 확보됐어야 한다. 10일·2순·3순 예측의 정답기간이 검증 구간과 겹치는 학습표본은 제거하고, 외부자료 시차·이동평균·스케일링·변수 선택은 각 학습 구간 안에서 결정한다. 일/주/월/분기 표시 변경 시에도 실제값의 집계 정의와 예측 기준시각을 유지한다.

본수집 보관은 향후 DuckDB 단일 파일의 원거래·외부관측·코드이력·공표버전·수집기록·타깃 테이블로 구성하고, 검증에 사용한 버전만 테이블/연도 단위 Parquet로 동결하는 안이다. 날짜별 소파일을 만들지 않는다. 검증 표본은 별도 SQLite 파일에 테이블로 정리했다(9절). 모델·대시보드는 개발하지 않았다.

## 8. 추가 신청 및 실험 시작 전 남은 확인

**신청 확인 완료: [aT 전국 공영도매시장 경매원천정보](https://www.data.go.kr/data/15141810/openapi.do).** 앞서 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(30)가 발생했으나 사용자의 신청 완료 통보 후 같은 키로 정상 조회에 성공했다. 이 API를 다시 신청할 필요는 없다. 현재 조사에서 추가로 신청해야 한다고 확인된 API는 없다. 과거 자료·수정 이력 등 제공 범위 확인은 API 승인과 별개다.

이 원천자료는 낙찰가·물량·총가격·낙찰일시·거래 식별자를 제공하므로 정산자료의 가격 산식 및 거래일 대응 검증에 필요하다. 다만 공식 명세에도 최초 공개·정정 버전 시각은 확인되지 않아, 승인만으로 과거 공개 이력 문제가 해결되지는 않는다.

별도 자료 제공/명세 확인이 필요할 수 있는 항목은 각 원 출처의 문의·자료요청 경로에서 다음과 같이 구체화한다. 현재 별도 요청을 대신 제출하지 않았다.

- [aT 정산정보](https://www.data.go.kr/data/15141809/openapi.do): 시장·품목별 최초 보유일, 이전 시스템 이관 전 자료, 최초 게시·수정/취소 시각 및 버전, 실제 총중량·평균가 정의, 시장별 휴장/누락 구분, 코드 유효기간·시장 이전 대응표.
- [관세청 품목별 통계](https://www.data.go.kr/data/15101609/openapi.do): 상세 HS 자료 공개 시점과 월별 발표본, 2022년 양파 구·신 코드 동시 응답의 집계 관계 및 연도별 대응표. 단순 추가 API 구독만으로 해결되는 문제는 아님.
- 공모전 공식 자료/안내: 경락가에 포함하는 매매구분·시장·품종·원산지·등급·집계식·휴장처리 및 정산일/낙찰일 기준. 공개 전까지 자체 타깃을 공식 정답이라고 표시하지 않음.

현재 진행 가능한 것은 원자료 수집·거래/코드 정합성 검증·공표 달력 구축이다. 모델 가설검증 시작 조건은 (1) 타깃 정의 고정, (2) 품목별 일별 연속기간 및 결측 유형 확인, (3) 당시 공개본 또는 후향적 검증 한계 명시, (4) 동일 평가구간과 기준모델 고정이다. 이후 사용자와 합의한 공모전 점수·MAE/MAPE·DM 검정을 적용한다. KREI는 계속 제외한다.

## 9. 경매원천 승인 후 실제 대조 결과

### 더 오래된 자료가 존재한다

정산 API와 원천 API의 제공 범위가 다르다. 원천 API에서 가락시장 전체 상품의 2014-01-03, 2014-06-16, 2015-06-15, 2016-06-15, 2017-06-15 자료가 존재했다. 가락 2013년 6~12월 월별 표본은 0건이었다. 따라서 **원천 API에서 가장 이른 양성 표본은 2014-01-03**이지만, 이를 최초 보유일이라고 확정하지 않는다. 2014-01-03 조회는 전체 상품 1행 존재 확인이며 5품목 모두의 시작일 확인이 아니다.

| 품목 | 원천 API의 2014년 실제 표본 | 해석 |
|---|---|---|
| 배추 | 2014-06-16 가락 285행·강서 15행 | 중분류 전체 거래 존재 |
| 무 | 같은 날 가락 120행·강서 11행 | 중분류 전체 거래 존재 |
| 양파 | 같은 날 가락 523행·강서 26행 | 중분류 전체 거래 존재 |
| 깐마늘 | 같은 날 소분류 `06`, 가락 85행·강서 38행 | 각 첫 5행의 법인품종명은 ‘깐마늘’, 매매구분은 정가수의. 전체 행의 거래방식 분포는 아직 미확인 |
| 건고추 | 2014-09-15 강서 4행 | 4행 모두 법인품목/품종명 ‘건고추’, 정가수의. 이 표본만으로 2014년 경매만의 타깃을 구성할 수는 없음 |

2014-06-16의 33시장 조사에서 배추·무·양파·깐마늘 후보 응답은 가락·강서에만 있었다. 건고추는 그날 전국 표본에서 0건이었지만 9월 강서에서 발견됐다. 2015-09-15 건고추는 33시장 모두 0건, 2016-09-19에는 대구북부·인천삼산·광주각화·안양·춘천·천안에 존재했다. **특정 날짜의 0건은 연도 전체 미보유나 시장 휴장을 의미하지 않는다.**

긴 자료 활용안은 시장별 원시계열을 보존하고, 동일 시장 집합의 장기 비교와 더 넓은 시장 집합의 최근 비교를 나누는 것이다. 2014년 2시장 가격을 최근 전국 가격과 그대로 접합하지 않는다. 시장 구성 비중, 참여 시장 수, 품목/매매구분 및 코드의 일관성을 검사하고 공식 타깃과 일치하는 기간을 별도로 정해야 한다.

### 원천과 정산의 금액·중량을 재현했다

대조 범위는 2018-01-15와 2026-09-23의 가락 배추·무·양파·마늘 전체, 광주서부 마늘 전체, 광주각화 건고추다. 12개 조건의 원천 2,452행과 정산 479행을 모두 받았고 페이지 누락은 없었다. 마늘 전체에는 깐마늘 외 품종도 들어 있으므로 최종 5품목 학습자료가 아니다.

- 정산일·시장·법인·매매구분·대/중/소분류·단위물량·단위코드·포장·크기·등급·원산지로 묶으면 **479개 정산행 모두 원천의 총금액 합과 총물량 합이 일치**했다. 모든 원천 표본의 단위는 kg이었다.
- 원천 2,452행 모두 `unit_tot_qty = unit_qty × qty`가 일치했다. 따라서 이 표본에서는 `qty`가 포장 단위 수량이고 `unit_tot_qty`가 kg 총물량으로 해석된다. 다른 단위·시장·시기에도 성립하는지는 본수집에서 검사한다.
- 정산 `avgprc`는 479행 모두 원천 `scsbd_prc`의 단순 산술평균과 1원 이내로 일치했다. 이는 표본의 경험적 확인이며 공식 전 범위 산식 보증이 아니다. 물량 가중평균과 동일하지 않으므로 `avgprc`를 다시 단순 평균하지 않는다.
- 단, **16행에서 `scsbd_prc × qty`와 `totprc`가 불일치**했다. 그중 2행은 낙찰가·수량·총금액이 모두 음수인 사례이고 나머지는 양수 금액 간 차이다. 예: 2018년 무의 7,400원×214는 1,583,600원이지만 총금액 응답은 1,712,000원이었다. 가격 변경·정정 또는 필드 의미 차이일 수 있으나 원인은 확정하지 않았다.
- **음수 거래는 총 5행**이다. 취소·정정 여부를 확인하기 전에 절댓값으로 바꾸거나 이상치로 삭제하지 않는다. 원천과 정산 재현 비교에는 원본 부호를 보존하고, 최종 타깃의 상계 규칙은 명세와 대조한다. 비양수 순중량 집계는 나누어 가격으로 만들지 않는다.

따라서 ‘공식 정산 금액 기준 단가’와 ‘낙찰가·수량으로 재구성한 단가’는 항상 같지 않다. 두 정의를 구별해 대조하고, 공모전이 사용하는 정의를 선택해야 한다. 정산 재현 성공은 공식 공모전 타깃 재현 성공과 다르다.

### 낙찰일·정산일·수정 관련 시각은 서로 다르다

원천 2,452행 중 253행의 `scsbd_dt`는 null이었다. 시각이 있는 2,199행은 정산일과 낙찰일의 달력 날짜 차이가 0일 70행, 1일 2,121행, 2일 8행이었다. 예를 들어 2026-09-23 정산에 2026-09-21 밤 낙찰이 포함됐다. 날짜별 모델 타깃을 만들 때 두 날짜를 혼용하지 않는다.

실제 응답에는 이전 공개 Swagger 필드 목록에 없던 `mdfcn_dt`가 있었다. **수정 관련 시각으로 보이지만 정확한 의미·시간대·이관 시 갱신 여부는 미확인**이므로 우선 원문 필드로 보존한다. 2018년 표본에는 모두 2025-11-26 시각, 2026-09-23 표본에는 2026-09-24~25 시각이 들어 있었다. 이를 거래 당시 최초 공개시점으로 간주하거나, 그 이전의 자료 버전을 복원하는 데 사용하지 않는다. 원천 API 승인으로 최초 공개 이력이 자동 확보된 것은 아니다.

역사적 코드 명칭에도 주의한다. 예를 들어 2018년 거래 응답에 현재 행정구역 명칭이 붙어 있어, 당시 코드명/경계를 보존한 자료인지 따로 검증해야 한다. 지역별 기상·생산 변수와 결합할 때 현재 명칭만으로 과거 산지를 일괄 매핑하지 않는다.

| `production_annual_samples` | 장기 조회 응답 466행. `-` 등 비수치도 보존. 실제 숫자 응답은 460행 |
| `study_metadata` | 공표일 사례, 대조 결과, 기간 표본, 사용 제한 |

원응답의 숫자는 소수 문자열 그대로 보존했다. `request_id + row_number`로 수집 근거를 연결하고, 거래 식별자 앞자리 0·공백·음수·null을 임의 변경하지 않았다. DB 무결성·출처 연결·테이블 행 수·품질 표시 합계를 확인했다. 기존 JSON 근거도 보존한다. 자동 수집기·모델·대시보드 구현은 수행하지 않았다.

다음 본수집은 원천의 긴 기간과 정산의 재현 가능한 기간을 병행하되 시장별 시작일·연속성 표를 먼저 만든다. 과거 당시 공개본이 없는 구간은 후향적 평가로 구분하고, 공식 타깃 정의와 맞춘 데이터셋에서만 모델 비교를 시작한다. 추가 활용신청이 필요한 것으로 확인된 API는 현재 없다.
