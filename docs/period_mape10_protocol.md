3.1 실제 MAPE를 학습목표로 만드는 수식
각 훈련행 i의 발행 당시 이미 알려진 기준가격 p_ref,i > 0, 해당 목표순 정답 Y_i > 0를 둔다. p_ref는 기존 B1의 로그가격비 학습에 사용한 정확히 동일한 기준가격 정의를 코드에서 확인해 사용한다. 임의로 B0b나 미래 순가격으로 대체하지 않는다.
r_i = Y_i / p_ref,i                # 훈련행의 양수 정답 가격비
x_i = 해당 원점에서 생성한 B1 입력 특징
f_theta(x_i) = intercept + beta·standardized(x_i)
pred_i = p_ref,i * max(0.05, f_theta(x_i))

실제 MAPE_i / 100 = abs(pred_i - Y_i) / Y_i
                       = abs(max(0.05, f_theta(x_i)) - r_i) / r_i
S: 훈련의 비율 r_i에 대한 제곱오차 Ridge. M/MW: 다음 단 하나의 구현식으로 MAPE를 직접 최소화한다. lambda는 계수 규제강도이며 절편은 규제하지 않는다. LP 목적에서 정답 역수 1/r_i를 정확히 한 번만 곱해야 한다.
M:   weighted_L1 = sum_i (1/r_i) * abs(r_i - f_i) / n
MW:  weighted_L1 = sum_i decay_i * (1/r_i) * abs(r_i - f_i) / sum_i decay_i

objective = weighted_L1 + lambda * sum_j abs(beta_j)
constraints: f_i >= 0.05 for every training row

decay_i = 2^(-age_in_completed_periods_i / 72)
이 구현식은 정답 r_i의 역수를 정확히 한 번 쓴다. M에서는 MAPE에 정확히 비례하고, MW에서는 최근 순에 더 큰 가중치를 준 MAPE를 최적화한다. 절댓값은 잔차의 양·음 분리변수를 통해 LP로 구현한다. 절편은 규제하지 않는다. 구현은 scipy.optimize.linprog(method="highs") 또는 등가의 명시적 LP를 사용한다.
중요: 양수 제약은 훈련행에서만 강제할 수 있다. 평가행은 진실값을 보지 않고 max(0.05,f)를 적용한다. 이 고정 범위 처리는 최초 프로토콜에 기록하고, 시험 오차를 보고 최솟값을 바꾸지 않는다. 시험에서 잘리는 출력 비율을 기록한다. 양수 정답을 잘라내거나 역수 가중치를 별도 상한으로 임의 절단하지 않는다.
3.2 같은 표현·같은 손실의 효과를 섞지 않는다
- R−F: 적합시점 갱신 효과(동일 정책·같은 가용 표본·동일 키 확인).
- W−R: 기존 로그제곱손실 아래 최근성 가중 효과.
- S−R: 목표·복원 표현 변경을 포함한 효과. 손실함수만의 인과효과라고 하지 않는다.
- M−S: 같은 비율 예측표현 안에서 제곱손실→MAPE 직접목적의 효과(규제 튜닝 절차까지 포함).
- MW−M: 직접 MAPE 목적 아래 최근성 가중 효과.
- M/MW−F, M/MW−B0: 실제 사용가치 여부.
3.3 최근성 가중
age_in_completed_periods는 적합 시점에서 해당 훈련 정답의 목표순이 끝난 이후 경과한 순 수다. decay=2^(−age/72)로 두어 약 24개월 전 순의 상대가중이 절반이다. W는 표본가중치 평균을 1로 정규화해 Ridge alpha의 상대 효과를 유지한다. R/W/S/M/MW의 표준화는 각 적합의 훈련행만을 사용하고, 같은 데이터·입력 공간을 비교할 때 변환을 공유한다. 2024~2026 전체자료로 표준화를 미리 적합하지 않는다.
4. 하이퍼파라미터와 선택: 2024~2026 시험을 보고 수정하지 않음
- R/W의 Ridge alpha는 기존 B1이 2022~2023 개발에서 선택한 {1,10,100} 값을 그대로 계승한다. 데이터 형태 변경 없이 R/W 차이만 비교한다.
- S의 Ridge 비율목표 alpha 후보는 {1,10,100}. M/MW의 LP lambda 후보는 {0.001,0.01,0.1}. 같은 품목·거리의 학습 prefix를 공유한다.
- 2020~2021의 분기별 대표 원점(각 분기 첫 합법 발행 1개)에 한해 S의 alpha와 M/MW의 lambda를 먼저 고른다. 선택 지표는 8셀 동일가중 MAPE를 우선, 동률이면 MAE, 다시 동률이면 더 강한 규제다. 이는 2022~2023 개발·2024~2026 평가점수를 활용한 규제 재탐색을 막기 위한 저비용 설정 탐색이다. 분기별 원점의 정답도 그때보다 미래인 학습에 소급 사용하지 않는다.
- 그 다음 2022~2023의 모든 합법 순 원점에서 R/W/S/M/MW를 같은 평가키로 굴려 개발 성능을 얻는다. 2022와 2023의 품목별 평균 MAPE·MAE를 반드시 따로 보고 한 해에서만 우연히 이긴 방법을 확인한다.
- 최종 후보 정책 P는 품목별로 한 방법을 선택하고, 그 품목의 2순·3순에 동일한 방법을 적용한다. 각 후보의 개발 점수는 (2022년 2순 MAPE + 2022년 3순 MAPE + 2023년 2순 MAPE + 2023년 3순 MAPE)/4이다. 먼저 각 해의 품목 2셀 평균 MAE가 같은 해 F의 105% 이내인 후보만 허용하고, 그중 개발 MAPE가 가장 낮은 것을 선택한다. 허용 후보가 하나도 없으면 신규 후보 중 개발 MAPE가 가장 낮은 구성을 진단용 위험 후보로 선택하고, MAE 보호조건 미달이라고 기록한다. 정확히 같은 점수(허용차 1e-10 이내)의 동률은 M→MW→R→W→S 순으로 결정한다. B0/F를 새 개선안으로 승격시키는 선택지는 없다. 선택한 P는 위험 후보 여부와 관계없이 전체 후향기간을 평가한다.
- 보조 정책 P_global: 2022·2023의 8셀 동일가중 MAPE가 가장 낮은 단일 신규 방법을 전체 품목에 적용. 이것은 진단으로만 평가하며, P와 좋은 기간별로 섞어 새로운 주정책을 만들지 않는다.
- 시험 2024-01~2026-09의 값은 선택·재튜닝·품목별 구조 교체·lambda 변경에 절대 쓰지 않는다. 단, 이전 연구에서 이 기간을 반복 열람했으므로 이번 결과도 독립적인 외부검증이라고 부르지 않는다.

6.2 실패를 다음 네 부분으로 분해
1. 국면 지연: R−F에서 개선이 있으면 오래된 적합 정책의 한계를 시사. 이미 동일하면 갱신 문제가 아니었다고 결론.
2. 최근성 효과: W−R와 MW−M의 월·연도별 개선·악화를 비교. 특정 해만 개선하면 최근성 자체의 일반적 우월성은 미확정.
3. 학습 목적의 불일치: M−S에서 직접 MAPE 학습이 비율제곱 모형보다 이기는지, MAE는 얼마나 희생하는지 기록. M−R에는 표현·손실 변화가 함께 들어 있음을 별도로 표시.
4. 고오차 구간: 배추·무의 고가격/저가격 순, 가격 급등락 순, 기준가격 신선도·순별 유효 관측일 수별 오류를 나누고, 저가격 구간의 소수 사례가 MAPE를 지배하는지 계산. 구간 선택은 진단 전용이며 평가에서 제외하지 않는다.
특히 깐마늘에서는 MAPE가 이미 10% 이내여도 MAE가 악화되면 성공이라고 쓰지 않는다. 새 방법이 배추·무를 크게 개선하는 대신 깐마늘을 훼손한다면 전체 MAPE10 목표와 가격 손해 사이의 충돌로 기록한다.
7. 통계와 결과 판정
- 평가 지표의 차이는 같은 품목 × 거리 × 목표순 × 발행원점의 정확히 동일한 쌍으로 계산한다. 기준선 누락을 후보 성공으로 바꾸지 않는다.
- 계획한 주 비교는 P−F 및 P−선택B0: 비교 2×8셀×AE/APE = 32개 가설. 순 단위 DM/HAC Bartlett lag3, lag6 민감도, 가족별 Holm 5%를 사용한다. P−F와 P−B0를 전체 32가설 한 가족으로 다룰지 두 가족으로 나눌지는 실행 전 프로토콜에 고정한다(권장: 전체 32가설 한 가족).

- 동일 목표순이 서로 다른 예측거리·품목에 등장하므로 공동 목표순 기준의 블록 재표집(길이 6/12순, seed0·2,000회)을 보조 분석한다. 블록 기간과 목표순 순서를 보존하고, 8셀을 독립 8배의 표본이라고 부르지 않는다.
- 관측 개선·통계적 우월성·모형 선택·공식 대회 채택은 다른 판단이다. 전체 후향 평가에서 개선돼도 이미 살펴본 기간의 반복 선택 편향이 남는다. 결과가 비유의하다고 관측 개선을 지우지 않고, 10% 목표 미달을 성능 성공으로 바꾸지 않는다.

- LP는 절편 무규제·계수 L1, 잔차 절댓값, 훈련행 f≥0.05를 명시적으로 구성합니다. solver 성공 외에 제약 잔차·목적값의 직접 재계산·유한성·저장 재로딩 예측을 검산합니다. 실패 시 낮은 점수로 대체하지 않습니다. 시험 출력 하한은 0.05로 고정하며 잘린 비율을 기록합니다.
- 주검정은 P−F 및 P−B0의 총 32개 가설을 하나의 가족으로, 기전 비교 64개는 별도 가족으로 고정합니다. 각 가족에서 HAC3와 HAC6별 Holm 5%를 적용하며 추론 불가 가설도 가족 크기에 유지합니다. 최소 고유 목표순 30개·양의 유효 분산이 필요합니다.

- 가격 진단의 고·저 구간은 품목별 2014~2021 유효 순 정답의 중앙값으로 고정합니다. 급등락은 abs(목표순 실제가격/p_ref−1)≥20%, 기준가격 경과일은 ≤2일·3~7일·≥8일, 목표순 관측일은 3~5일·6~8일·≥9일로 나눕니다. 실제 정답을 쓰는 구간은 사후 원인 설명 전용이며 예측·선택·평가 제외에 사용하지 않습니다. 월·연도·계절 구분도 진단 전용입니다.
- 최초 LP 한 건의 시간은 전체 수행시간의 확정값으로 취급하지 않고, 예정 적합수·이력 증가 비용과 함께 견적으로 보고합니다. 코드·설정·원천이 일치하는 체크포인트만 재사용합니다. 특정 월이나 품목을 성적에 따라 생략하지 않습니다.
