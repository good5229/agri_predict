2. 이 가설을 선택한 이유와 검증 범위
최신 보고서에서 고정 MLP 은닉표현의 대체 M, 출력층 재적합 H, 기존 R을 유지한 직교 잔차 보정 S는 종료됐다. S는 훈련 손실을 줄였지만 V의 직접 예측과 최종 결합 가격오차를 개선하지 못했다. 따라서 같은 은닉표현에서 층·epoch·출력 가중치만 바꾸는 후속은 이번 실험에 포함하지 않는다. 근거는 제공 보고서 §12.7~12.8이다.
현재 기본 Ridge는 같은 품목의 열 개 예측거리를 별도로 적합한다. 이번에는 거리별 차이를 허용하면서도, 가까운 거리의 가격 반응이 완전히 독립적일 필요는 없다는 제약을 시험한다. 새로운 변수를 더하지 않으므로, 입력 정보의 변경과 추정 방법의 변경을 섞지 않는다.
“거리별 독립 적합의 추정 불안정이 현재 실패의 원인”은 아직 확정된 사실이 아니다. 검증할 가설은 다음 세 가지다.
가설	필요한 대조	관찰할 결과
H1. 추가적인 복잡도 축소가 도움이 된다	D와 B	같은 입력에서 축소만으로 오차가 낮아지는가
H2. 거리 사이의 계수 공유가 축소만 하는 것보다 유용하다	C/P와 D	맞춘 유효복잡도에서 공유 조건이 더 나은가
H3. 실제로 가까운 거리끼리 연결하는 것이 유용하다	C와 P	같은 유효복잡도에서 실제 거리 순서가 더 나은가


다중 과제의 관계를 정규화에 넣는 방법은 기존 연구에 근거가 있다. 그러나 그 연구가 이 농산물 데이터의 성능 개선을 보장하지는 않는다.[1] 이 문서의 품목, 연결 순서, 규제량, 진행 조건은 이번 실험을 위한 사전 설계다.
초기 pooled Ridge는 하나의 반응계수를 여러 거리에 적용한 방식이다. 이번 방식은 열 개의 계수를 유지하고 계수 차이에 벌점을 준다. 구현을 시작할 때 PLAN.md, multiscale_direct_cv.py 등에서 동일한 거리 계수 공유가 실제로 완료됐는지 짧게 대조한다. 명칭이 비슷하다는 이유로 같은 실험으로 보지 않는다. 정확히 일치하는 기존 적합물이 있으면 재사용한다. 이 문서 작성 단계에서 해당 프로젝트 코드 전체를 직접 확인한 것은 아니다.
3. 네 실험 조건
ID	무 직접모델	연결 또는 벌점	역할
B	기존 h별 독립 Ridge	기존 alpha=10만 적용	E106 재현 기준
D	독립 Ridge + 추가 대각 벌점	C 벌점행렬의 대각항만 사용, 거리 간 교차항 없음	일반적인 추가 축소 대조

P	순서 변경 계수 공유 Ridge	1–6–2–7–3–8–4–9–5–10	실제 인접 순서의 필요성 대조


C와 P는 모두 경로 그래프다. 양 끝을 1과 10으로 유지하므로 각 거리의 연결 수가 같고, 좌표 변환 전 그래프의 고유값도 같다.
D는 추가 벌점의 자기 항을 보존하고 거리 간 결합 항을 제거한다. D/C/P의 규제계수는 뒤의 규칙으로 **같은 총 유효자유도(EDF)**에 맞춘다. 따라서 규제계수 자체는 서로 다를 수 있다. C−P는 “동일 EDF를 갖도록 보정한 두 연결 정책”의 비교이며, 같은 규제계수에서 순서만 바꾼 순수 효과라고 표현하지 않는다.
D/P는 원인 판별용이다. 이들이 C보다 좋아도 이번 실험에서 대신 승격하지 않는다. 별도 성능 탐색으로 해석될 후보 교체를 방지하기 위한 규칙이다.
4. 시간 분할과 미래정보 차단
4.1 월별 확장 학습
기존과 같은 월 첫 적격 원점에 모델을 적합한다. 해당 월 모델이 갱신되기 전의 과거 원점에 그 모델을 소급 적용하지 않는다.
기호	의미
u	훈련 표본의 과거 예측 원점
h	예측거리, 1~10일
u+h	해당 훈련 표본의 정답 날짜
f	실제 모델 적합 원점
o	평가 예측의 원점
o+h	평가할 목표일


적용 규칙은 다음과 같다.
1. 훈련 표본의 특징은 u−1일까지의 정보로 계산한다.
2. f에서 사용하는 훈련 정답은 u+h ≤ f−1일이어야 한다. 공개 가용시각이 기록돼 있으면 그 시각도 f 이전이어야 한다.
3. 평가 예측의 특징과 p0는 o−1일까지의 정보로 계산한다.
4. 해당 예측을 생성한 모델은 f ≤ o를 만족해야 한다.
5. 표준화, 기준 좌표, EDF, 추가 규제계수는 그 적합의 훈련 X만으로 정한다.
6. h별 훈련행 수가 달라도 기존 행을 유지한다. 열 거리의 공통 완결 행만 남겨 훈련자료를 줄이지 않는다.
7. 월별 적합 원점·갱신 정책은 기존 구현과 일치시킨다. 모든 h의 기존 적합 시점을 확인하고, fitId로 묶는다. 목표월만 보고 잘못된 적합물을 연결하지 않는다.
예를 들어 4월 1일 적합 시 u=3월 30일의 h=1 정답인 3월 31일 가격은 가용 조건을 충족하면 쓸 수 있다. 같은 u의 h=10 정답인 4월 9일 가격은 쓸 수 없다.
5월 이후 적합에서 이미 도착한 4월 정답을 사용하는 것은 위 규칙에 따른 순차 재학습이다. 4월의 평가점수를 보고 규제량·연결·가중치를 바꾸는 행위는 허용하지 않는다.

5. 모델과 목적함수
5.1 기존 Ridge와 정확히 맞출 부분
각 거리 h에서 다음을 유지한다.
- 기본40 특징, StandardScaler, Ridge(alpha=10, fit_intercept=True).
- 목표: y_h = log(목표가격 / p0).
- 2014년 이후 가용 이력의 확장 학습, 최소 훈련 정답 90개.
- h별 훈련행·훈련 전처리·표준화·원점별 입력.
- 기존 라이브러리 환경과 가격 변환·fallback 정책.
horizonDays는 h별 적합에서 상수다. 원래 40열 스키마는 보존하되 그 계수는 0으로 고정하고 공유 대상에서 뺀다. 나머지 39개 기울기 × 10거리 = 390개 기울기를 적합한다. 절편 10개는 독립적으로 유지한다. 다른 상수열은 기존 스케일러의 scale_=1 처리를 유지하고 임의로 삭제하지 않는다.
기존 Ridge의 기본 목적함수는 SSE에 alpha 벌점을 더한 것이다.[2] SSE를 거리별 MSE로 바꾼 채 alpha=10을 유지하면 기존 규제 강도가 달라지므로 금지한다.
5.2 서로 다른 스케일러의 좌표를 맞춘다
h별 훈련행 수가 다르므로 특징의 표준편차도 다를 수 있다. 표준화된 계수 beta_h를 그대로 서로 비교하면 같은 원단위 반응을 잘못 묶을 수 있다.
해당 월 h=1의 훈련 스케일러를 기준으로 다음을 정의한다.
sigma_h   = h의 기존 훈련 scaler.scale_  (39열)
sigma_ref = h=1의 훈련 scaler.scale_
D_h       = diag(sigma_ref / sigma_h)
q_h       = D_h beta_h
Dcoord    = blockdiag(D_1, ..., D_10)
q_h는 공통 기준 단위에서의 기울기다. 기준 좌표는 해당 적합의 훈련 특징만 사용한다. 절편은 공유하지 않는다.
각 h의 표준화된 훈련 X와 y를 열 평균 기준으로 중심화해 기울기를 풀고, 절편은 해당 훈련 y 평균과 X 중심화 값을 통해 복원한다. 평균·표준편차·열 순서를 저장하고 예측에도 동일하게 적용한다.
5.3 세 추가 벌점
G  = blockdiag(X_h.T @ X_h)                  # 중심화된 훈련 X
Q0 = G + 10 I

P_C = Dcoord.T @ (L_C ⊗ I_39) @ Dcoord       # 실제 인접 경로
P_P = Dcoord.T @ (L_P ⊗ I_39) @ Dcoord       # 고정 순서 변경 경로
P_D = diag(diag(P_C))                       # 결합 교차항 제거

J_A(beta, b)
  = sum_h { ||y_h - X_h beta_h - b_h||² + 10 ||beta_h||² }
    + lambda_A * beta.T @ P_A @ beta

A ∈ {D, C, P}
위 목적함수에서 X_h를 중심화해 사용하면 b_h는 해당 y 평균이다. 원래 스케일러 좌표로 출력할 때는 저장한 중심화 평균을 반영한다.
C의 추가 벌점은 인접 q_h 차이의 제곱합이고, P는 고정된 다른 연결의 제곱합이다. B는 추가 벌점이 0인 경우다.
일반적인 multioutput Ridge를 호출하는 것만으로 위 거리 공유가 구현되지는 않는다. 명시된 블록 목적함수를 직접 구성해 안정적인 선형계 풀이로 계산한다.
6. 추가 규제량: 점수 탐색 없이 EDF를 맞춘다
임의로 작은 lambda를 넣고 “공유가 효과 없었다”고 판단하는 일을 피하기 위해, D/C/P가 실제로 같은 양의 유효복잡도를 줄이도록 한다. EDF는 학습값에 대한 선형 평활행렬의 trace로 정의한다.[3]
6.1 고정 목표
절편을 제외한 기울기의 EDF를 다음과 같이 계산한다.
df_A(lambda) = tr[ G @ (Q0 + lambda P_A)^(-1) ]
df0          = tr[ G @ Q0^(-1) ]

Tshared = vertical_stack(D_1^(-1), ..., D_10^(-1))

df_inf = tr[
  (Tshared.T @ G @ Tshared)
  @ (Tshared.T @ Q0 @ Tshared)^(-1)
]

df_target = df_inf + 0.75 * (df0 - df_inf)
df_inf는 C/P에서 규제를 무한히 강하게 했을 때 공통 기울기로 공유되는 한계다. 총 모델 EDF를 표시할 때는 독립 절편 10개를 더한다.
고정한 것은 df0−df_inf의 25% 감소다. 전체 EDF를 25% 줄인다는 뜻이 아니다. 0.75는 이번 실험의 단일 고정 설정이며 성능을 보고 바꾸지 않는다.
D의 대각 벌점에서는 무한 규제의 기울기 EDF가 0으로 향하지만, D도 C/P에서 정한 동일한 절대 목표 df_target에 맞춘다.
6.2 계산과 예외
1. 각 월의 훈련 X로 df0, df_inf, df_target을 계산한다.
2. D/C/P별로 df_A(lambda_A)=df_target을 만족하는 lambda_A를 수치적으로 푼다.
3. EDF 허용오차는 1e-6 × max(1, df0)로 고정한다.
4. df0−df_inf가 같은 허용오차 이하이면 조절 가능한 복잡도가 없다고 기록한다. 해당 단계는 intervention_not_identifiable로 중단하고 T로 진행하지 않는다. 임의 lambda로 대체해 정상 개입처럼 보고하지 않는다.
5. lambda의 탐색 구간 확장·근찾기는 훈련 X의 단조 방정식을 푸는 작업이다. 평가오차를 쓰는 하이퍼파라미터 탐색이 아니다.
6. 양의 정부호 선형계 풀이·안정적인 대칭 고유값 분해를 사용한다. 역행렬이나 표본 수×표본 수 hat matrix를 직접 만들 필요는 없다.
7. 모든 월의 규칙을 동일하게 적용한다. 수치 실패가 나면 명시된 수식을 만족하도록 구현을 수정하고 예측 전체를 다시 고정한다. 해결하지 못하면 numerical_failure로 단계를 종료하며, 이를 모델 성능 실패로 집계하지 않는다. 점수에 맞춘 설정 변경은 하지 않는다.
같은 EDF는 같은 편향·분산이나 같은 예측 변화량을 보장하지 않는다. 총 EDF 외에 거리별 EDF 기여량, 계수 차이, 실제 예측 변화량을 저장해 어디에 변화가 배분됐는지 확인한다.
7. 성능 채점 전에 통과할 구현 검산
다음은 정확한 비교를 성립시키는 검산이다. 성능 개선을 대신하는 성과로 보고하지 않는다.

8. 예측과 평가 지표
8.1 최종 비교가격
direct_A(o,h) = p0(o) * exp(predicted_log_return_A(o,h))
blend_A(o,h)  = 0.5 * direct_A(o,h) + 0.5 * same_causal_SARIMA(o,h)
유효한 SARIMA가 없을 때의 처리와 발행 보류는 기존 E106 정책을 그대로 적용한다. 신규 실패를 기존 예측으로 조용히 덮어 정상 후보 발행으로 세지 않는다.
B/D/C/P는 같은 무 발행키에 예측을 생성한다. 배추·양파·깐마늘은 기존 E106을 그대로 연결한다. 기존 미래 발행물과 이전 실험 파일을 덮어쓰지 않는다.

품목·거리·목표월별 전체 지표와 고유 목표일 수를 남긴다. 기존 깐마늘 실험의 618쌍을 이번 무 표본 수로 사용하지 않는다.
8.3 추론
- 사전 검정 가족: C−B, C−D, C−P × 10거리 × AE/APE = 60검정.
- 기존 검증된 달력 목표일 기반 DM/HAC 구현을 사용한다. 실제 날짜 간격을 보존한 Bartlett HAC9를 주 분석, HAC28을 민감도 분석으로 둔다.

- 무 10거리 평균 차이의 불확실성은 목표일을 공동 재표집하는 14일/28일 달력 블록, 각 2,000회, seed=0으로 계산한다. 모든 비교조건·거리·결측마스크에 같은 추출을 적용한다.
- 블록은 해당 구간의 연속 달력 날짜에서 추출하고 원래 구간 길이에 맞춘다. 휴장·무거래일을 지워 연속 관측일 블록으로 바꾸지 않는다. 복제별 유효성·유효 반복 수를 남기고 분위수 95% 구간을 보고한다.
- 여러 거리나 겹치는 월별 훈련 적합을 독립 날짜처럼 세지 않는다.
이 구간의 반복 탐색 전체가 Holm으로 통제되는 것은 아니다. 신뢰구간과 p값은 이번 고정 비교의 후향 불확실성을 설명하며, 독립적인 미래 우월성을 인증하지 않는다.
9. 실패 원인을 수치로 분해하는 필수 진단
9.1 개입이 실제로 발생했는가
월×조건별로 다음을 저장한다.
- df0, df_inf, df_target, 실제 EDF, lambda, 거리별 EDF.
- B 대비 q_h 변화량, 실제 인접 순서의 계수 차이 제곱합.
- 원래 그래프에서 계산한 추가 벌점값과 전체 목적함수.
- B 대비 예측 로그비 변화의 RMS, 최대 절댓값, 변경된 발행키 수.
- 같은 훈련행에서의 순수 로그비 MSE와 V의 로그비 MSE를 분리한 표.
실제 예측 변화가 작다는 이유로 사후에 lambda를 키우지 않는다. EDF를 줄였어도 현재 예측에 중요한 방향은 거의 바뀌지 않을 수 있다. 이 경우는 “개입이 예측에 전달되지 않음”으로 보고하며, 공유 일반의 실패로 확대하지 않는다.
9.2 오차 변화의 항등 분해
각 조건 A에 대해 같은 정답 쌍에서 다음을 계산한다.
e_B = actual_log_return - predicted_log_return_B
d_A = predicted_log_return_A - predicted_log_return_B

MSE(A) - MSE(B)
  = mean(d_A²) - 2 * mean(e_B * d_A)
먼저 h별로 계산한 뒤 동일가중한다. C−D와 C−P도 기준을 각각 바꿔 같은 분해를 계산한다. 훈련과 V/T, 목표월별 결과를 구분한다.

10. 진행·보존·중단 조건
10.1 V에서 T로 진행
수치·정보 검산이 성립한 상태에서 C가 다음을 모두 만족하면 T를 수행한다.
1. 무 10거리 동일가중 결합 MAPE가 B/E106보다 낮다.
2. 같은 기준의 결합 MAE가 B/E106보다 높지 않다.
3. B 대비 추가 발행 누락·fallback·보류·coverage 손실이 없다.
표시용 반올림 전 값으로 판정한다. 완전히 같은 예측이나 MAPE 동률은 개선으로 세지 않고 E106을 유지한다.
Holm 유의성, 모든 거리·월의 동시 개선, D/P에 대한 유의 우월성은 새 진행 문턱으로 추가하지 않는다. D/P는 실패 기전을 설명하는 대조군이다.
C가 V 조건을 실패하면 T의 후보 적합·생성·채점을 하지 않고 not_run_validation_failed로 기록한다. 나쁜 V의 원인을 찾기 위해 T 정답을 열람하지 않는다.
10.2 T 이후 판단
V 통과 시 B/D/C/P 모두 같은 정책을 유지해 T에서 비교한다. 월별 X에 따른 lambda 재계산은 이미 고정한 갱신 정책의 실행이며 설정 변경이 아니다.
- T에서도 C가 같은 가격·coverage 조건을 만족하면 E106-RHS를 후향 개선 후보로 보존한다.
- 실패하면 기존 E106을 유지한다.
- 통계적 우월성의 확인 여부는 별도로 적는다.
- 운영 반영이나 과거 발행물 교체까지 자동 승인된 것으로 해석하지 않는다.
11. 구현 순서·산출물·일정
11.1 실행 순서
1. 사전 고정: 이 문서와 설정을 저장하고 코드·원천·환경·기존 E106 manifest를 연결한다. 새 결과를 보기 전에 품목, 구간, 그래프, EDF 규칙, 평가 가족, 중단 조건을 고정한다.
2. 구현: 사용자 지정대로 Luna가 Python을 작성한다. 기존 특징·스케일러·타깃 생성 함수를 재사용한다. Astra가 대상 파일 전체와 정보시점·목적함수·EDF·표본 연결을 검토한다.
3. B 및 수치 검산: 월별 입력을 한 번 구성해 네 조건이 공유한다. B와 lambda=0 재현, 그래프, 선형계, EDF를 확인한다. 과거 상태가 없으면 승인된 이 과거 실험 범위에서 재적합한다.
4. V 생성·고정·채점: 네 조건의 전체 예측을 정답 없이 저장하고 해시를 고정한다. 이후 정답 연결, 가격 평가, 기전 진단, 고정 통계를 한 번 수행한다.
5. 조건부 T: V 통과일 때만 같은 절차를 T에 적용한다. 실패면 미실행 사유를 남긴다.
6. 최종 결정: E106 유지 또는 후보 보존, 실패 위치, 확인하지 못한 원인, 제안서에 쓸 수 있는 숫자를 한 장 요약으로 작성한다.
실제 프로젝트의 승인 범위에 따라 학습 실행을 관리한다. 이 지시서 작성은 학습 실행·대회 제출 자체를 수행한 것이 아니다.
