3.2 대상·발행·정답 및 학습 정보 경계
- 기존 고정 가상 순별 정답 유지: 한 달의 1~10, 11~20, 21~말일. 실제 양수 일가격이 3일 이상이면 관측일 가격의 산술평균을 대리 순가격으로 사용한다. 거래량 가중 전국 공식가격이라고 부르지 않는다.
- 발행 시각은 완료순 종료+2일 10시 KST라는 기존 가정. 입력 cutoff는 발행일−2일. 현재 산출물의 정확한 origin_id, 목표순, 날짜 집합을 우선 재사용한다.
- 입력은 각 역사 원점 당시 cutoff 이전 관측만, 모델 훈련행은 해당 목표순 종료+2일 ≤ 현재 적합시점인 것만 사용한다. 최종 정답을 미리 공개됐다고 가정하는 코드를 허용하지 않는다.
- 정답이 나중에 개정된 원천인 한 과거 최초 공개판의 재현은 미입증이라는 제한 유지. 대리 공개+2일은 실험용 가정이며 실제 공식 마감시각이 아니다.
- 결측일·휴장·무거래·수집실패를 구분하며 실제 관측하지 않은 가격을 직전가격으로 채워 정답을 만들지 않는다.
- 동일 목표순이 2순/3순 발행행에 중복될 수 있다. 각 row와 고유 (crop, target_period) 수를 구분해 보고하고 통계에서 독립 표본으로 세지 않는다.

- G에서는 수치형 피처를 억지로 전체 기간 표준화하지 않는다. L은 동일 허용 훈련자료에서 scaler를 적합한다. 공통 피처의 의미와 계산 단위는 같게 유지한다.
- 반응변수(두 모델 공통): z = log(Y_proxy(c,k,origin) / p_ref(c,origin)). 복원은 forecast = p_ref × exp(pred_z)이며 실제 가격 MAE/MAPE는 복원값으로 평가한다. 로그공간 손실 개선을 MAPE 개선으로 대체하지 않는다.
- 출력은 유한·양수여야 한다. 비유효 발생 시 정책 사전 규칙으로 P에 기술 복귀하고 원시값·건수·발행 비율·주점수를 기록한다. 복귀를 후보 성공이나 자가선택으로 표현하지 않는다. 원자료가 없는 키는 원인별로 기록하고 키 교집합 삭제로 감추지 않는다.
3.4 순별 목표 중복과 8셀 균형 가중
훈련행은 crop × h × original_origin을 기반으로 구성한다. 같은 (crop, target_period) 정답이 2순/3순에서 여러 번 쓰였으면 그 중복 횟수를 m_{crop,target}로 세어 원행의 첫 가중치를 1/m으로 둔다.
그다음 각 crop×h 셀의 가중치 합이 전체의 1/8이 되도록 셀별로 재정규화하고, 전체 가중치 평균은 1이 되도록 곱한다. L과 G는 정확히 같은 sample weight를 받는다.
- 이는 같은 정답을 독립적으로 여러 번 관측했다고 가정하지 않고 학습에서 과대표집을 완화하려는 설계다. 같은 순을 다른 원점에서 예측하는 정보 자체는 유지한다.
- m과 셀별 총수는 현재 적합 이전에 실제로 이용 가능해진 훈련행만으로 계산한다. 미래 전체 기간의 중복 수를 미리 써서는 안 된다.
- 적격 8셀 중 훈련행이 없는 셀이 있으면 부족 사유를 남기고 모델 적합을 차단한다. 무조건 다른 셀로 채우거나 점수 계산에서 제외하지 않는다.
3.5 G와 L의 구체적 학습 설정
기존 실행 환경에 LightGBM이 사용 가능한지 먼저 확인한다. 이미 검증된 라이브러리·가상환경을 우선 재사용한다. 새로운 패키지 설치·버전 변경이 필요하면 실제 작업 범위를 보고 승인받고, 조용히 대체 라이브러리를 설치하거나 다른 모델로 바꾸지 않는다.
G: 동일한 regression_l1(로그가격비의 절대손실)과 seed42, num_threads=1, deterministic 설정을 고정한다. 후보는 개발구간에서만 다음 세 가지로 제한한다.
설정	max_depth	num_leaves	min_data_in_leaf	learning_rate	n_estimators	lambda_l2
G-A: 강규제	2	4	60	0.03	200	30
G-B: 기본	3	7	40	0.03	300	10
G-C: 반응성 확대	3	7	25	0.03	400	5


그 외 feature_fraction=1, bagging_fraction=1, bagging_freq=0, max_bin=63, verbosity=-1, force_col_wise=True로 고정한다. Early stopping은 당시 적합원점 이전으로만 구성한 내부 validation이 마련된 경우에만 사용한다. 기본 실행에서는 위 지정된 tree 수로 적합하고 시험 성적을 보고 트리 수를 바꾸지 않는다. GPU·대형 신경망·설정 무제한 탐색은 사용하지 않는다.
L: 같은 학습행·피처·반응변수·가중으로 **StandardScaler(훈련전용)+Ridge(alpha=10, fit_intercept=True)**를 각 원점에 적합한다. L의 절대손실이 G와 다르므로 비교의 해석 한계는 §3.1에 명시했다. alpha=10은 진단용 사전 설정이고 L의 최적화 주장 대상이 아니다.
3.6 개발 선택 (2022~2023)과 과거 평가 (2024~2026-09)
자료 구간	역할	시간 제한
2014~2021	순차 학습 시작을 위한 역사자료	과거 원점별 입력/정답 만기 제한 유지
2022~2023	G-A/B/C 개발 비교 및 한 정책 동결	해당 시점 이전 자료로 각 발행 원점의 pooled 모델을 새로 적합. 개발 정답은 동일 과거 원점의 예측 생성 뒤에만 평가용으로 연결
2024-01~2026-09	동결된 G 하나 + L 한 가지를 780 공통 키 전체 후향 평가	P·B0의 기존 저장 예측·대리 정답과 8셀에서 직접 비교. 2024-2026도 이전부터 본 후향 탐색 구간


개발 평가에서 G의 각 설정을 8셀 동등가중 MAPE8로 비교하되 다음 조건으로 고정한다. MAE8 ≤ P_개발_MAE8 × 1.03인 설정 중 MAPE8 최저를 선택하고, 없으면 MAPE8 최저 설정 하나를 선택해 MAE 보호 미통과를 명시한 상태로 시험도 실행한다. 동률이면 G-A→G-B→G-C 순서로 선택한다.
- 개발 모델 선택과 과거 평가의 적합 갱신 주기를 일치시킨다: 매 합법 발행원점에서 당시 공개·만기된 정답만으로 하나의 pooled 모델 재적합.
- P를 G의 신규 입력이나 교사 목표로 쓰지 않는다. P는 동등 키 가격 비교에만 사용한다.
- 시험에서 2024년 성능이 나쁘다는 이유로 2025/2026을 중단하지 않는다. 2022·2023 점수가 좋다는 이유로 2024~2026 성적을 미리 성공이라고 주장하지 않는다.
- 시험 점수로 G-A/B/C, 품목별 사용지도, 원가격 복원방식, 예측거리별 계수나 B0 혼합비를 변경하지 않는다. 시험은 한 번의 동결 정책 평가이며, 실패해도 모두 보고한다.
3.7 자원·실행 상한
- pooled 모델은 원점당 1회 적합으로 네 품목×두 거리 8개 출력을 생성한다. 품목×거리마다 따로 8개 모델을 만드는 방식이 아니다.
- 예상 시행원점은 2022~23년 약 72회, 시험 약 99회이며, G 개발 3설정과 G 시험 1설정, L 개발·시험 1설정씩의 명목 적합은 약 486회다. 실제 원점 수·가용성·지원은 사전검사에서 계산하고 fit-ledger에 정확히 남긴다.
- 하드 상한 600 적합. 예상 초과 시 품목/기간/후보를 몰래 잘라내지 말고 작업 범위 승인 여부를 확인한다. 신규 원천 수집·기존 V3 7,356 적합 반복·장기 신경망 학습은 포함하지 않는다.
- 캐시·훈련 행·정답 기준·출력 유효성 및 사용자 지정 코드검토 절차를 지킨다. 실행 중 이전 결과가 나쁘다고 해석해 계획을 바꾸지 않는다.
4. 반드시 얻어야 할 결과와 실패 진단
4.1 주 성능과 도전 목표
모든 구성 B0/P/L/G를 동일한 원점×품목×2순/3순×동일 대리 정답에서 비교한다. 780은 이전 실험의 기존 비교키 수이지 독립 표본 780개가 아니다.
평가	필수 출력
주 비교 G−P	MAPE8 차이(%p), MAE8 차이(원/kg), 동일키 coverage, 각 품목×거리·연도별 차이
보호 비교 G−B0	MAPE8와 MAE8. 전체 MAE는 B0 221.2328원/kg도 별도 보호 기준
구조 진단 G−L	같은 원천·피처·학습행의 pooled tree와 pooled 선형의 성능 비교
도전 목표	MAPE8 ≤10%, 그리고 개별 8셀 중 ≤10% 셀 수 (두 판정 독립 표기)
기간별	2024/2025/2026(1~9월) 동일가중 MAE8·MAPE8와 각 셀 원수치


실질 성과 단계: (a) G가 P 대비 MAPE8 감소, MAE8 비악화, coverage 유지하면 관측 개선; (b) G가 B0 MAE도 넘어서면 추가 실용 조건 충족; (c) MAPE8≤10%는 별도 도전 목표. 이 세 판정을 하나로 합치지 않는다. 사전 통계적 우월성 조건은 독립 표기하되, 비유의 결과를 성능 동등으로 취급하지 않는다.
4.2 정답 확인 후 실패 위치 구분
같은 키·동일 8셀 분모에서 아래를 모두 산출한다. 단계별 분해는 진단이지 평가정답으로 예측 알고리즘을 바꾸는 실시간 규칙이 아니다.
1. 풀링의 기여/비선형 관계: G−L이 개선되는데 G−P는 악화하면 global tree 자체의 일부 기여가 있어도 기존 강한 정책에는 미달한 것으로 판단. 두 구성 모두 악화하면 현재 입력과 pooling/트리 구조가 기준 우위로 이어지지 않은 것. G−L 자체는 손실·규제 차이가 섞여 순수 비선형의 인과 분해가 아님.
2. 품목 간 공유 위험: 배추·무·양파·깐마늘별 MAE/MAPE를 나누고 한 품목(특히 깐마늘)의 가격 규모가 전체 MAE를 지배하는지 8셀 가중 기여를 계산. 관측시점 불일치를 품목 간 관계 변화로 단정하지 않는다.
3. 급등락/평상시: |Y_proxy/p_ref - 1| ≥ 0.20은 사후 진단용. 큰 급변의 비중·손실과 비급변 손실을 나란히 계산. 정답 없이 급변을 미리 구분하는 규칙을 설계·홍보하지 않는다.
4. 모델의 반응성: pred_z 및 log(Y_proxy/p_ref)의 분포, 평균 예측 변화 부호, 상단/하단 실제 가격 변화에서의 편향을 진단. G가 P보다 과소/과대반응하는지 수치로 설명하되 미래 방향을 사전에 식별했다고 주장하지 않는다.
5. 학습 지원 및 기간 유지: 원점별 학습 고유 (crop, target_period) 수, 셀별 결측·정답 만기, 2024/25/26 정책 점수. 기준선 대비 손실이 증가한 정확한 품목·기간을 추적한다.
6. 누수/보정 오류 차단: 과거 원점 이후 데이터를 일부 변경해도 그 이전 feature/fit/output이 불변인지 테스트. 저장 모델을 재로딩해 예측가격이 일치하는지 확인. 위반은 blocked_integrity, 성능 악화와 구분.
4.3 통계평가·결론
- 주 가족: (G−P, G−B0) × 8셀 × (AE, APE) = 32가설.
- 별도 구조 가족: (G−L) × 8셀 × (AE, APE) = 16가설.
- 사전 비교 가족마다 달력 순 인덱스 Bartlett HAC lag3(주)/lag6(민감도) + Holm 5%, 공통 목표순의 6/12순 블록 재표집 2,000회·seed0을 동일하게 적용한다. 개별 셀 DM과 전체 평균의 블록 구간은 다른 추론 대상이라고 명시한다.
- 양수 정답이 없거나 발행 실패한 키는 사유를 남기고 주평가에서 묵살하지 않는다. 공통 780키 전부 발행 가능한지 확인하며, 불가 시 coverage 손실로 보고한다.
- 2024~2026은 이미 반복 검토한 개발 구간이고 최초 공개판은 복원되지 않았다. Holm은 이번 가족 내부를 보정할 뿐, 이 프로젝트의 수십 차례 적응적 탐색을 취소하지 않는다. 유의한 개선 없음과 관측 개선 없음을 혼동하지 않는다.
- 평가 완료 조건: 실제 2024~2026 모든 합법 평가 기간에서 G와 L의 발행·점수·실패분해를 마친다. 개발 실패를 이유로 테스트를 미실행 처리하지 않는다. 성능 악화도 완료·미채택으로 보존한다.
