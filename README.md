# 농산물 가격예측 연구 — Agri Predict

**프로젝트 종료: 2026-10-28.** 국내 농산물 가격을 예측하고 그 근거와 불확실성을 보여주기 위한 연구·대시보드 프로젝트다. 데이터 수집, 시계열 전처리, 모델 비교, 통계 검토, 아이디어 제안서 작성을 수행했다. 사용자의 결정으로 추가 수집·학습·운영을 종료하고 코드와 문서를 공개 보관한다.

순별 연구 후보의 전체 MAPE는 13.478%로 단순 기준의 15.732%보다 낮았지만, 목표였던 전체 MAPE 10%는 달성하지 못했다. 일부 후향 개선과 별개로 공식 대회 성능, 충분한 전향 검증, 실제 수익 개선은 입증하지 않았다.

## 1. 기획

2026 AI 농산물 가격예측 온라인 해커톤의 아이디어 기술서를 준비하면서, 단순 가격표를 넘어 **향후 가격·예측 기준시점·자료 품질·예상 범위와 배경**을 함께 제시하는 도구를 목표로 했다. 출하·판매 시점 판단을 돕는 것이 활용 시나리오였으며, 실제 의사결정 편익은 별도 검증 대상이었다.

- 초기 대상: 배추·무·양파·깐마늘·건고추. 건고추는 거래 희소성·상품 구성 문제로 후반 연구 범위에서 보류하고 네 품목에 집중했다.
- 일별 연구: 향후 1~10일 가격, 재학습 주기 및 품목별 모델을 비교했다.
- 순별 연구: 2순·3순 뒤의 대리 순가격을 직접 예측했다. 일별 모델과 다른 목표·평가 체계다.
- 대시보드: 실제·예측 가격, 품목·기간·예측거리 선택, 순차 평가 재생, 성능과 자료 부족 상태를 구현했다. 기획한 모든 설명·범위 기능이 완성된 것은 아니다.

공식 대회 목표의 정의·배포 자료와 자체 도매시장 대리 타깃을 구분했다. 연구 후보를 성능 확인 없이 운영 모델로 바꾸지 않았고, 이 저장소는 대회 제출·수상·상용화의 증빙이 아니다.

KREI는 제외했다. 정부 문서에 섞인 KREI 유래 사실도 정부 자체 발표·조사와 구분했다. 외부 자료를 확보했다는 사실만으로 실제 모델 입력 채택이나 정확도 개선을 주장하지 않는다.

수집기는 요청 상한, TLS 검증, 제한 재시도, 체크포인트, 페이지 완결 검사와 중복 실행 잠금을 사용했다. 원응답·URL·수집시각·해시·판본을 보존하고 실패, 정상 빈 응답, 휴장, 품목 무거래를 구분했다. 최초 확인시각을 과거 게시일로 소급하지 않았다.

배추·무 공급 원문은 2026-10-16부터 실제 확인시각을 누적했으며, 마지막 정상 수집은 **2026-10-27 18:14~18:16 KST**였다. 해당 실행은 목록 8페이지·본문 26건·PDF 36건의 70개 응답을 검증했다. 이는 마지막 실행의 조회 범위이며 전체 역사자료의 규모나 독립 공급사건 수가 아니다. 프로젝트 종료와 함께 자동 수집을 중단했다.

상세 범위·출처·수집 이력은 [수집 실행 기록](docs/COLLECTION.md), 초기 가용성 조사는 [데이터 확보 조사](docs/data-feasibility.md)에 있다.

## 3. 전처리

1. **가격 정의를 고정했다.** 두 시장의 적격 경매·kg 거래를 중심으로 `부호 있는 총금액 합 ÷ 부호 있는 총중량 합`으로 일가격을 구성했다. 깐마늘을 마늘 전체로 대체하지 않고 확인된 소분류를 사용했다.
2. **정정과 결측을 보존했다.** 음수 정정, 원천 소수 문자열, null을 유지하고 잘못된 단위·코드·비양수 순집계는 사유를 남겼다. 날짜 공백을 가격 이월로 채워 평가 표본을 늘리지 않았다.
3. **미래정보를 차단했다.** 특징 생성·표준화·선택·훈련은 각 원점에서 확보 가능한 자료와 성숙한 정답만 참조하도록 설계했다. 수정일·경매시각·관측일을 최초 공표시각으로 간주하지 않았다.
4. **정보 가용성과 목표를 분리했다.** 일별 가격, 순별 대리목표, 전국 가격, 다른 유통 단계 가격을 같은 계열로 취급하지 않았다. 공급 문서의 수확률·면적·품질을 근거 없이 공급 톤수로 환산하지 않았다.
5. **같은 표본에서 비교했다.** 원점·목표일·품목·거리 키를 맞추고 예측 보류·미성숙 정답·자료 부족·복귀를 별도 기록했다. 계절·연도·급변 구간과 coverage도 확인했다.

현재 수정본을 사용한 후향 연구에서는 원래 공개판과 시각을 모두 복원하지 못했다. 시점 제한을 구현한 것과 엄격한 실시간 재현을 달성한 것은 다르다.

## 4. 모델링

직전가격 유지 기준선에서 시작해 Ridge, 부스팅 트리, SARIMA와 고정 결합, 직접 예측, 품목 공동학습, 계절 유사사례, 신경망·Chronos-2, 공급정보 보정 등을 비교했다. 실험은 앞선 실패에 대한 가설·추가 정보 또는 제약·비교군·중단 기준을 먼저 기록하고 진행했다. 모든 후보가 최종 채택된 것은 아니다.

일별 계열에서는 Ridge·SARIMA 결합과 E106 등 연구 후보를 구분해 관리했다. 순별 연구의 최종 보존 후보는 **품목·거리 공동학습 직접 LightGBM G-B(V5)**이며, 타 품목의 현재 값을 입력하는 방식이 아니라 과거 훈련행을 공유하는 방식이다. 일별 발행 정책을 이 후보로 교체하지 않았다.

### 순별 연구의 핵심 결과

아래는 **2024-01~2026-09**, 네 품목 × 2순·3순의 8셀을 같은 키로 비교한 후향 결과다. MAPE8·MAE8은 셀별 지표의 동일가중 평균이다.

| 구성 | MAPE8 (%) | MAE8 (원/kg) | 판정 |
|---|---:|---:|---|
| B0 단순 기준 | 15.732254 | 221.232782 | 비교 기준 |
| P 기존 선택 정책(V3) | 14.327883 | 225.495917 | B0 대비 MAPE 감소·MAE 증가 |
| G-B 공동 LightGBM(V5) | **13.478028** | **212.886231** | 연구 후보 보존, 전체 10% 목표 미달 |
| D1 공급 수치 보정(V8 탐색) | 13.742386 | 214.686524 | G-B보다 악화, 미채택 |
| C 가격기반 보정(V9) | 14.331570 | 221.764568 | G-B보다 악화, 미채택 |

비교키는 780개지만 고유 목표순은 98개, 품목×목표순은 392개다. 이를 독립 표본 780개로 해석하지 않는다. 계획 792행 중 기존 정책 비가용 12행은 유지했고, G-B는 780개 비교키에서 추가 누락 없이 직접 예측했다.

**통계 평가:** 짝지은 MAE·MAPE, 시간 의존성을 반영한 Diebold–Mariano 검정, Holm 다중비교 보정과 공동 목표순 블록 재표집을 수행했다. V5 주 비교 32가설에서 HAC 3순/6순의 유의 개선은 각각 2건/3건이고, 두 대역폭 공통 유의 항목은 B0 대비 배추 3순 APE였다. 블록 6순/12순의 평균 MAPE 차이 95% 구간은 G-B가 P·B0보다 낮았으나, MAE 차이 구간은 0을 포함했다. 따라서 평균 MAPE의 제한된 후향 개선 근거와 MAE의 통계적 불확정을 함께 인정한다.

2026년 1~9월만 보면 G-B는 P보다 MAPE가 0.234778%p, MAE가 21.878408원/kg 높았다. 전체 평균 개선을 모든 연도·품목·급변 구간의 개선으로 일반화할 수 없다. V8의 공급 보정과 V9의 가격 보정은 통계 평가까지 마친 뒤 미채택했다. 비유의 결과는 동등성의 증거가 아니다.

자세한 사전 규칙·실패 결과·표본 제한은 [전체 기획 및 실험 기록](docs/PLAN.md), [V5 동결 프로토콜](docs/period_pooled_lgbm_protocol.md), [V3 결과](docs/순별예측_MAPE10_실험결과_2026-10-16.md)에 남겼다. 이 종료 작업에서는 새 학습이나 결과 재선택을 하지 않았다.

## 5. 결론

가격·물량 이력과 공동학습으로 일부 후향 MAPE를 낮출 수 있었지만, **전체 10% 목표 및 안정적인 전향 우월성은 입증하지 못했다.** 모델을 더 복잡하게 만들거나 동일 정보에 보정을 반복하는 것이 일관된 개선으로 이어지지 않았다. 희소한 공급 수치의 단순 연결도 추가 예측편익을 보이지 못했다. 이는 공급정보 자체가 무용하다는 결론이 아니라 이번 자료·표현·기간에서의 결과다.

남은 핵심 한계는 공식 목표와 대리 타깃의 차이, 역사 판본·공개시각 미복원, 반복 사용한 후향 평가기간, 급변 구간 대응, 희소 품목과 공급지표의 지원 부족이다. 실제 판매 수익·의사결정 개선도 평가하지 않았다. 연구 구현과 관측 개선을 사용자 편익의 입증으로 바꾸어 보고하지 않는다.

**2026-10-28 사용자 결정으로 프로젝트를 종료한다.** 코드, 검증 규칙, 성공·실패 판단과 최종 제안서를 보관하고 정기 수집·발행·평가를 중단한다. 후속 연구나 서비스 운영을 약속하지 않는다.

과거 문서의 `data/`, `outputs/`, `runs/` 링크·해시는 당시 로컬 산출물의 참조이며 **원격 저장소에 해당 파일이 없으므로 열리지 않는다.** 로컬 원자료와 생성 산출물도 종료 정리 과정에서 삭제하므로 이 저장소만으로 동일 결과를 재현할 수 없다. 다시 실행하려면 적법하게 원자료·인증정보를 확보하고 환경·입력 경로를 재구성해야 하며, 재수집한 수정본은 원래 결과와 달라질 수 있다.

### 코드 확인과 실행 환경

핵심 수집 코드는 Python 3.10 이상과 시스템 `curl`, 대시보드는 Node.js 18 이상을 전제로 한다. `requirements-modeling.txt`는 초기 모델 계열의 환경 기록이며 모든 후속 실험의 의존성을 포괄하지 않는다. 후속 LightGBM·PyTorch·Chronos·statsmodels 실험의 별도 환경과 버전은 해당 코드·프로토콜을 확인해야 한다. 일부 실행 스크립트와 연구 코드에는 당시 로컬 절대경로가 남아 있다.

```bash
# API 호출·학습 없이 핵심 수집기의 명령 도움말 확인
python3 -m agri_data.collector --help

# 기본 대시보드 검사 (Node.js 18+)
npm run test:dashboard

# 화면 서버 실행: 표시할 데이터는 별도로 준비해야 한다
./start-dashboard.sh
```

종료된 연구 코드의 보관본이며, 새 복제본에서 자동 수집·전체 실험·완성된 대시보드가 즉시 작동한다는 보장은 없다. 본 저장소의 실험 성능을 공식 점수나 수익 보장으로 해석하지 않는다.
